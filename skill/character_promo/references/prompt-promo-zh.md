# 美宣 Prompt 系统

继承 `art-prompt-system.md` 所有规则。

**美宣的核心任务**：用一张图讲一个关于这个角色的故事，让玩家看一眼就记住她。构图/光线/场景的决策优先级**高于**服装细节。

consistency_level: `loose`

---

## 一、写 prompt 前的输入核查

| 输入项 | 来源 | 缺失时 |
|---|---|---|
| spec.md 视觉锚点（全部） | spec.md | 必须先有立绘 spec，否则退回 `/character-workflow` |
| `narrative_beat` | 画师要求 | **必填，不允许为空**。"凄美"不是 narrative_beat，"闭眼跪地准备最后一次唤神"才是 |
| `target_aspect_ratio` | 画师要求 | 必填。见画幅映射表 |
| `text_zone` | 画师要求 | 默认 `否`。是否预留文案留白区 |

**narrative_beat 不能为空的原因**：没有情节锚点，模型会退化成把所有细节堆在一起，输出"华丽但无情绪"的立绘变体，而不是能讲故事的美宣。

---

## 二、画幅 → 构图映射

拿到 `target_aspect_ratio` 后，按以下映射确定构图策略。这一步在写 prompt 前完成，不在写的过程中摸索。

| 画幅 | 构图策略 | 典型用途 |
|---|---|---|
| `16:9` 横版 | 角色占左侧或右侧 2/3，另侧留场景/文案空间；或角色居中 + 全景场景铺满 | 官网 KV、横幅广告 |
| `4:5` 竖版 | 角色占 3/4 画幅，场景紧凑收拢，视觉张力集中 | 社媒竖版卡、手机壁纸 |
| `1:1` 方图 | 角色半身特写 + 氛围背景，快速传递情绪 | 头像卡、商品方图 |
| `9:16` 全竖 | 角色全身 + 场景纵深，视角感强 | 手机闪屏、Story 广告 |

---

## 三、决策顺序：先光线，后服装

**这是美宣与立绘最本质的区别。**

光线决定情绪基调 → 情绪基调决定场景温度 → 场景温度决定服装细节该强调什么。

把光线留到最后写等于把情绪交给模型猜。写之前先在脑子里回答这一句话："这张图的光从哪里来，打在什么上面，产生什么情绪？"

---

## 四、段落结构与每段规则

### 第1段：情节 + 角色锚点

**写什么**：角色在做什么（具体动作 + 情绪状态）+ 场景时空（地点 + 时辰/天气）+ spec 关键锚点词（发色/瞳色/服装主色，嵌入句子，不单独罗列）。

**规则**：
- `narrative_beat` 必须转化为具体动作描述。"孤独"不行，"独站高塔边缘，风将发丝从耳后带走，不回头"才行
- 场景时空必须给具体值。"夜晚"太虚，给"子夜，月被云蚀只剩一弧白光"
- 这段是全 prompt 的叙事锚，决定后续所有段落的情绪方向

### 第2段：光线 + 色彩基调

**写什么**：光源方向 + 光源性质（硬光/柔光/体积光）+ 主色调 + 辅色调 + 明暗对比关系 + 是否逆光/剪影。

**规则**：
- 这段每个值必须具体，不允许模糊。"暖光"不够，给"黄昏低角度侧逆光，主色暖金，阴影面冷蓝灰，高对比"
- 若有第二光源（法杖/武器/道具发光）必须单独说明，给色温和亮度关系
- 先定光的方向（叙事情绪），再决定辅色（视觉平衡），而不是反过来
- 剪影处理是情绪放大器，但会损失服装细节 —— 使用前问画师是否接受

### 第3段：构图 + 镜头

**写什么**：视角选择 + 焦点物体 + 画幅比例 + 留白策略 + 文案预留区位置（若 text_zone = 是）。

**视角决策规则**：

| narrative_beat 情绪类型 | 推荐视角 |
|---|---|
| 史诗/战前/仪式/降临 | 低视角仰拍，角色有压迫感 |
| 内心独白/决意/静默 | 平视，镜头感克制 |
| 凝视/审视/俯瞰全局 | 略俯视，角色有掌控感 |
| 颓然/失落/虚弱 | 略俯视或平视，不做仰拍 |

**焦点规则**：焦点必须是"决定这张图情绪的那个元素"—— 可以是脸、手、武器、特定道具、甚至一块空白。说清楚，不要让模型猜。

### 第4段：风格与质感

**写什么**：风格档（继承 spec，写 spec 里的原话）+ 参考画派 + 细节密度 + 是否有特殊处理（留白/印象式笔触）。

**规则**：
- loose 模式允许强化光影风格（比 spec 更戏剧化的光影处理），但基础风格类型不变（半写实不变卡通）
- 细节密度：注意力越集中的区域细节越高，其他区域可适当简化（裙摆/背景做留白处理）
- 禁止写 `细节丰富` `精细刻画` 等无意义词，改为具体说哪里高细节

## 五、参考图处理（继承 art-prompt-system 第五节）

美宣是**双图思维**最重的图类：立绘是隐式 subject_image（保证人是谁不变），画师上传的氛围参考是 reference_image（决定这张图的味道）。

| 配置 | subject_image | reference_image |
|---|---|---|
| 默认（无画师上传图） | `portrait/v_latest.png`（隐式，spec 锚点等价） | 无 |
| 画师上传氛围参考图 | `portrait/v_latest.png`（隐式） | 上传图，默认 mode = `full_reference` |
| 画师上传光影/色调参考 | `portrait/v_latest.png`（隐式） | 上传图，mode = `color_lighting_only` |
| 画师上传姿势参考 | `portrait/v_latest.png`（隐式） | 上传图，mode = `pose_only` |

**写 prompt 时的参考图表达**：

- **无上传图**：第1段照常写情节 + spec 锚点。spec 锚点本身履行 subject_image 的职责。
- **有上传图，full_reference**：第2段（光线 + 色彩）后补一句："参考上传氛围图的整体风格、构图、光影和色调（full_reference），人物身份仍以角色 spec 为准；若上传图中有人物参与展示的画面关系，保留这种关系但重新生成符合本角色的人物形象，不复制其面部、服装和身份。"
- **有上传图，color_lighting_only**：第2段末尾补一句："参考上传图的色彩系统、冷暖关系和光影氛围（color_lighting_only），不参考其主体、构图或人物。"
- **有上传图，pose_only**：第1段（情节）末尾补一句："姿势参考上传图（pose_only），不参考其角色身份、服装和场景。"

**禁止**：
- 禁止在 prompt 中写"完全照搬上传图"—— 没有任何一种 mode 是这个意思
- 禁止省略 mode 声明，让模型猜
- 禁止写"删除上传图中的人物" —— 应写"重新生成符合本角色的人物，保留其展示关系"

## 六、质量门控

| 检查项 | 不通过时 |
|---|---|
| narrative_beat 已转化为具体动作？ | 退回，继续问画师"她在做什么动作" |
| 光线已确定方向和色温？ | 返回第2段补完 |
| 构图策略与画幅匹配？ | 按画幅映射表核对 |
| prompt 中所有 spec 锚点（发/瞳/服装）均正确继承？ | 退回修正 |

## 七、排除段模板

```
排除：现代感元素、网文滥词、平光均匀打亮、四肢比例变形、低质量、与 spec 不符的角色配色
```

## 八、示例

### 16:9 横版 KV · narrative_beat = 末战前夕 · text_zone = 是

```
圣灵祭祀，单膝跪地闭眼低首，金发金瞳，白金圣袍；法杖横置膝前，准备最后一次唤神召灵。神殿外廊尽头，黄昏，远处战火将云层右侧烧成橙红，场景从右暖向左冷渐变。

黄昏低角度侧逆光从右后方打入，主色暖金，角色迎光面金光灼烧感，阴影面冷蓝灰；法杖顶端冷白光晕作为第二光源，与暖色主光形成冷暖张力；背后半透明圣徽金色虚影。

16:9 横版，低视角仰拍，构图重心偏左下，法杖竖线对齐画面中轴，右侧三分之一为云层和战火留白，文案区预留在右上角深色区域。

半写实精修，参考 Ross Tran / Loish 暖调厚涂，角色局部高细节，裙摆与背景做渐进留白，整体像真实游戏宣传 KV 而不是运营活动图。

排除：现代感、平光、网文滥词、四肢变形、低质量、卡通夸张脸
```

### 1:1 方图 · narrative_beat = 剑成那一刻 · text_zone = 否

```
剑客少年，右手将一柄刚淬好的宝剑缓缓抬起至眼前，浅银色目光沿剑脊平视刃尖，黑发被剑气带起几缕；铁匠铺火炉背景，夜深，炉焰在画外。

炉火高饱和橙红从右侧下方打上来，剑刃右侧反光橙红，剑脊左侧冷蓝钢色，两色在剑面形成分割；面部右侧被暖焰侧光照亮，左侧沉入阴影；整体高对比、低亮度。

1:1 方图，平视，焦点在刀锋与少年眼睛的对视关系，人物占画面 60%，背景炉火虚焦柔化，构图重心偏右上。

半写实精修，参考日本游戏原画武侠风格，剑面金属材质高细节，面部和手部高细节，服装中等细节，背景极简留白。

排除：卡通夸张、现代感、平光、过曝白化、四肢变形、低质量
```
