# 美宣 Prompt 模板（中文 7 段式）

美宣图与立绘的本质区别：**立绘是"角色长什么样"，美宣是"角色在做什么、为什么让你忘不掉"**。所以模板里"场景 + 情绪 + 构图 + 光线"四段比立绘八段更密集。

## 模板

```
<角色主体（沿用 spec 视觉锚点：发色 / 瞳色 / 服装 / 武器）>，<职业/气质>。
<场景与时空>：<地点>，<时辰>，<天气/氛围>。
<情绪 + 动作>：<一句话刻画"她在做什么"+ 表情>。
<构图与镜头>：<视角（仰角/平视/俯视）>，<焦点（脸/手/道具/某处空白）>，<留白策略（满 vs 大留白）>。
<光线与色调>：<光源方向>，<主色 + 辅色>，<对比度>，<是否逆光/侧光剪影>。
<风格与笔触>：<沿用 spec 风格档>，<参考画派/IP>，<细节密度（写实精修 vs 印象式笔触）>。
<画面规格>：<比例（16:9 横版 KV / 4:5 竖版 KV / 1:1 单卡）>，<分辨率>，<构图重心位置>。
```

## 例：圣灵祭祀的"末战前夕" KV

```
圣灵祭祀，金白圣袍，金发金瞳，右手持光辉法杖。
场景：神殿外回廊尽头，黄昏时分，远处战火映红半边云层。
情绪 + 动作：闭眼低头，单膝跪地，法杖横置面前，准备最后一次唤神。
构图：低视角仰拍，法杖在画面中轴，她的脸只露半边在光里，背后半透明圣徽虚影。
光线与色调：逆光剪影，主色暖金 + 辅色冷青衣襟阴影，高对比，金属反光锐利。
风格与笔触：半写实精修，参考 Loish / Ross Tran 暖调厚涂，细节密度高，但裙摆做留白处理。
画面规格：16:9 横版 KV，1536×864，构图重心偏左下，右侧留白给文案。
```

## 写作要点

1. **第一段沿用 spec**。如果 prompt 第一段写的角色配色与 `spec.md` 已确定要点不符 → 退回去问"这次要重定义视觉吗？"
2. **场景 + 时辰 + 天气 必给具体值**。"夜晚" 太虚，给 "子夜三更，月被云蚀剩一弧白光"。
3. **情绪段要带动作**。"凄美" 不行，"垂眸跪在祭坛前抚胸前圣徽" 才行。
4. **光线段决定整张图的氛围**，比服装段优先级高。先问光，后问衣。
5. **不要的元素 → 排除段**：`排除：现代元素、卡通脸、过曝、四肢变形、低质量、网文滥词如"凄美绝色"`
6. **默认 n=1**，画师明示"多出几张/对比"才改。
