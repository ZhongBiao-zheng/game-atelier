# 中文 Prompt 模板

## 为什么用中文

画师用中文沟通，prompt 也用中文，便于他直接读、改、复制到其它工具复用。Lovart / GPT Image 2 / Nano Banana / Seedream 都对中文支持良好，无需翻译。

## 模板结构

```
<主体>，<职业/身份>，<性别/年龄段>，<核心气质>。
<服装>：<主色调> + <辅色>，<材质细节>，<服装关键元素>。
<头部>：<发型/发色>，<头饰>，<表情>。
<道具>：<手持/佩戴/光效>。
<姿势与构图>：<全身/半身/三视图>，<站姿/动作>，<视角>。
<场景与光线>：<背景>，<光源方向>，<氛围>。
<风格>：<写实/半写实/卡通>，<参考画派>，<细节密度>。
<画面规格>：<比例>，<分辨率>，<构图重心>。
```

## 示例（圣灵祭祀）

```
神圣祭祀，神官女性，二十岁出头，神圣庄严、略带忧悯。
服装：圣洁白袍 + 金色刺绣镶边，丝绸质感垂坠，胸前圣徽，长袖摆地。
头部：浅金色长卷发披肩，金色细发冠点缀光宝石，平静低垂的眼神。
道具：右手持高过头顶的金色权杖，杖顶嵌发光圣晶，左手抚胸前圣徽。
姿势与构图：全身正面，双脚自然分开微站，俯仰角度平视略仰。
场景与光线：神殿中央石阶，逆光从背后金色穹顶洒下，柔和神圣光晕环绕全身。
风格：半写实游戏角色立绘，欧式奇幻画风，皮肤与织物高细节质感。
画面规格：竖构图 2:3，4K，居中构图，留白干净适合做角色卡。
```

## 写作要点

1. **具体 > 笼统**。"金色刺绣镶边" 比 "豪华服饰" 强 10 倍。
2. **每个维度一行**。让画师扫一眼就能定位哪行要改。
3. **画师明确不要的元素 → 写 negative prompt 段**：

   ```
   排除：现代元素、卡通脸、过曝、四肢变形、低质量
   ```

4. **不要逐字翻译英文 prompt 习语**。"masterpiece, best quality, 8k" 这种废话堆叠在中文里读起来很奇怪，且这些词对现代模型几乎无效。改写为"高细节、影视级质感"等更具体的描述。

5. **首次出图先生成 4 张做对比**，画师选定方向后再细化 prompt 出第二轮。
