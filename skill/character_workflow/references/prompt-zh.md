# 中文 Prompt 模板

画师全程中文链路，prompt 也用中文，便于他直接读、改、复用。Lovart / GPT Image 2 / Nano Banana / Seedream 都对中文支持良好。

## 8 段式模板

```
<主体>，<职业/身份>，<性别/年龄段>，<核心气质>。
<服装>：<主色调> + <辅色>，<材质细节>，<服装关键元素>。
<头部>：<发型/发色>，<头饰>，<表情>。
<道具>：<手持/佩戴/光效>。
<姿势与构图>：<全身/半身/三视图>，<站姿/动作>，<视角>。
<场景与光线>：<背景>，<光源方向>，<氛围>。
<风格>：<写实/半写实/卡通>，<参考画派>，<细节密度>。
<画面规格>：<比例>，<分辨率>，<构图重心>。
```

## 写作要点

1. **具体 > 笼统**。"金色刺绣镶边" 比 "豪华服饰" 强 10 倍。
2. **每个维度一行**，让画师扫一眼就能定位哪行要改。
3. **不要的元素 → negative prompt 段**：`排除：现代元素、卡通脸、过曝、四肢变形、低质量`
4. **不要逐字翻译英文习语**。`masterpiece, best quality, 8k` 这种废话在中文里读着怪，且对现代模型几乎无效。改写为"高细节、影视级质感"等具体描述。
5. **首轮 4 张做对比**，画师选定方向后再细化 prompt 出第二轮。
