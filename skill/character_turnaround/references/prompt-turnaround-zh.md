# 三视图 Prompt 模板（中文 5 段式）

三视图与立绘 / 美宣的本质区别：**立绘是"角色长什么样的一张"，美宣是"角色在做什么的一张"，三视图是"同一个角色从三个面看分别长什么样的一张横幅图"**。所以模板必须把三面比例、配色一致、道具多面呈现这三件事钉死。

## 模板

```
<角色主体（严格沿用 spec：发色 / 瞳色 / 服装 / 武器 / 头身比）>，<职业/气质>。
<视图组合>：正面 / 侧面 / 背面 横向排列，三面身高比例严格一致，<是否包含 3/4 视角 / 表情包 / 道具特写>。
<服装与道具的多面呈现>：<正面看的服装重点>，<侧面武器佩戴位置 / 披风长度>，<背面披风纹饰 / 绑带细节>。
<画面规格>：横幅 1536×1024，浅灰背景或浅色网格，三面均匀分布，留出基线/头顶线辅助识别比例。
<风格与笔触>：<沿用 spec 风格档>，线稿清晰 / 平涂上色 / 半厚涂任选其一，避免环境光与阴影干扰角色识别度。
```

## 例：圣灵祭祀的三视图

```
圣灵祭祀，金白圣袍祭祀长袍 + 兜帽，金发金瞳，右手持光辉法杖，七头身比。
视图组合：正面 / 侧面 / 背面 横向排列，三面身高严格对齐，正面包含面部完整结构，无 3/4 视角，无表情包。
服装与道具的多面呈现：正面看金线刺绣胸口圣徽与垂下的玉佩；侧面看法杖斜挎在右肩、披风从锁骨往下展开;背面看披风内衬冷青色金线神兽纹与发尾束起的金箍。
画面规格：横幅 1536×1024，浅灰背景配头顶/腰部/脚底三条辅助基线，三面均匀分布，每面占画面 1/3 宽度。
风格与笔触：半写实精修线稿 + 平涂上色，参考 ArtStation character sheet 风，细节密度均衡，无戏剧化光影，避免环境光干扰识别。
```

## 写作要点

1. **第一段沿用 spec**。如果三视图里写的角色配色与 `spec.md` 已确定要点不符 → 退回去问"这次要重定义视觉吗？"，绝不在三视图里偷偷改。
2. **视图组合段要明示是否包含表情包 / 道具特写**。下游建模师只要正/侧/背三面，画卡牌的会需要表情包。
3. **多面呈现段是三视图独有**。立绘 prompt 没有这一段 —— 三视图必须说清"从某面看新增哪些细节"。
4. **画面规格固定 1536×1024 横幅**。不要 1:1 / 9:16 —— 三视图本质是横版工序图。
5. **风格段拒绝戏剧化光影**。"逆光剪影 / 暗黑氛围"在三视图里会掩盖结构 → 改用"平涂 / 浅光 / 线稿清晰"。
6. **不要的元素 → 排除段**：`排除：戏剧化光影、强烈阴影、动态飞溅、特效粒子、面部夸张表情、低质量、四肢比例错位`
7. **默认 n=1**，三视图本身已经是三联横幅，几乎不需要 n=4 对比版本。画师明示"再来一版" 才改。
