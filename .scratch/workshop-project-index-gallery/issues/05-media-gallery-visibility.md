# 05：UI 与视频资产的项目画廊可见性

Type: fix

Status: done

Blocked by: 04

## Scope

- UI 页面版本图在资产详情显示当前项目画廊可见性，并支持隐藏与恢复。
- 视频镜头版本和成片在资产详情显示当前项目画廊可见性，并支持隐藏与恢复。
- 复用统一隐藏清单，不增加新的资产状态或兼容路径。
- 操作期间禁用当前媒体控件，失败时给出就地错误提示。

## Acceptance

- 隐藏清单中的 UI 页面图、镜头视频和成片显示“恢复展示”，点击后从隐藏清单移除。
- 可见媒体显示“从画廊隐藏”，点击后写入隐藏清单。
- sidecar 相对路径与前端绝对路径继续按现有后缀规则匹配。
- UI、视频详情与现有创作台隐藏功能回归通过。
