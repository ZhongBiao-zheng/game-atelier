# PRD：工坊项目索引与跨媒体项目首页

Status: done

## 目标

把工坊根页改成项目卡片墙，并把单项目首页恢复为“项目经验 / 世界观 + 项目画廊”的阅读页。项目画廊统一展示美术图片、UI 页面图和视频产出，但不取代资产库的生产管理。

## 用户路径

```text
/workshop 项目卡片墙
  → 新建项目 / 打开项目
  → /workshop/:projectId/overview 项目首页
  → 媒体预览
  → 角色、UI 页面或视频资产详情
```

进入项目后，侧栏为“项目切换器 + 当前项目导航”；切换项目统一回到目标项目首页。

## 验收规则

- 工坊根页无项目列表侧栏，新建项目是卡片墙第一张卡。
- 项目卡只有最新四图拼贴、完整名称、活动时间与管理菜单。
- 项目经验 / 世界观默认阅读，显式进入编辑态。
- 项目画廊包含全部未隐藏的美术/UI 图片及视频成品版本，按时间倒序并支持分类过滤和渐进加载。
- 参考图、源图、上传素材目录、策划文档和失败记录不进入画廊。
- 图片与视频先在统一预览层打开，再进入对应资产详情。
- 项目内不再出现重复的顶部“概览 / 美术 / UI / 视频”导航。
- 375、768、1440 三档可用，键盘、焦点恢复、Back 和刷新行为有回归测试。

## 不做

- 手动封面、项目统计面板、团队协作、标签系统、数据库媒体索引。
- 在项目画廊内承担版本定稿或生产编辑。
- 重命名历史 `/art` 路由。
