# PRD：创作台产物归档到项目资产

Status: done

## 目标

让创作台中已经完成的单张图片或单个视频，可以明确归档到某个游戏项目的正式资产位置，而不是长期停留在无归属的自由试验历史中。

## 核心规则

- 原 Studio 产物保留，归档采用复制，不移动源文件。
- 一次只归档一个产物，必须显式选择项目和具体资产目标。
- 图片可进入角色槽位或 UI 页面；视频只可进入视频企划镜头。
- 归档后创建新的正式 DONE Job，保留原 Prompt、模型、参数和来源 Job / 路径。
- 只有归档生成的新版本进入项目资产库；Studio 历史仍保持原样。

## 不做

- 批量归档、自动猜测项目或目标。
- 创建角色、UI 页面、视频企划或镜头。
- 移动或删除 Studio 源文件。
- 自动定稿、自动选版或自动加入项目文件夹。

## 实施顺序

```text
01 后端归档契约与复制闭环 → 02 创作台归档弹层
```
