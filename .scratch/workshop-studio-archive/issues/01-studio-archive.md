# 01：创作台单产物归档到项目资产

Type: feature

Status: done

## Scope

- 提供项目级归档目标清单：角色槽位、UI 方案页面、视频企划镜头。
- Studio DONE 产物可复制到所选正式资产目录，使用下一个 `vN` 文件名。
- 归档创建新的正式 Job，并记录 `archived_from_job_id / archived_from_path`。
- 创作台每个 Studio 产物提供“归档到项目”入口。
- 归档弹层按项目、资产域、具体目标逐级选择，含加载、空、失败和成功反馈。

## Acceptance

- 图片不能归档到视频镜头，视频不能归档到角色或 UI。
- 来源路径必须属于指定 Studio DONE Job，目标必须属于所选项目。
- 原 Studio 文件与 Job 不变；目标文件和新 Job 可在对应项目资产详情中读取。
- 同一目标重复归档会顺序生成 `v1 / v2 / ...`，不覆盖已有版本。
- 弹层可键盘操作、可取消，提交中禁用确认按钮；错误就地显示。
- 后端、前端、375 宽度和生产构建验证通过。
