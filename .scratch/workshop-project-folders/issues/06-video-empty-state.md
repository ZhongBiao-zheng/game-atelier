# 06：视频工作区空状态进入正式企划流程

Type: fix

Status: done

Blocked by: 05

## Scope

- 视频总控 Skill 已上线后，删除空状态中“去创作台试验视频”的旧入口。
- 空状态只保留一个主操作：复制 `/game-atelier:video`，用于建立项目视频企划。
- 明确说明复制后回到对话发送，视频总控会建立 Brief 与镜头表。
- 复制成功与失败都提供就地反馈；失败时保留可手动选择的命令文本。

## Acceptance

- 无视频企划时不再把用户导向自由试验创作台。
- 点击“复制新建企划指令”会复制 `/game-atelier:video` 并显示成功反馈。
- Clipboard 不可用时显示明确错误，命令文本仍可手动复制。
- 空状态保持单一主操作、键盘焦点与 Atelier 设计规范。
