# 03：拥有完整流程的角色皮肤

Type: task
Status: ready-for-human
Blocked by: 02

## What to build

把角色皮肤建成母角色下的角色变体：继承身份锚和项目风格,同时拥有独立 Spec、立绘、美宣、三视图、Job、反馈、版本和定稿。

## Acceptance criteria

- [x] 可从资产库或项目文件夹选择母角色并创建皮肤。
- [x] 从文件夹创建的皮肤自动加入当前文件夹,真实资产仍归项目资产库。
- [x] 皮肤详情显示母角色关系,并能进入完整三槽位流程。
- [x] 生成上下文包含项目风格、母角色身份锚、皮肤差异和当前槽位。
- [x] 皮肤的定稿、反馈和历史不覆盖母角色或其他皮肤。
- [x] 同一皮肤可以加入多个项目文件夹。
- [x] 创建、上下文解析、出图归属和页面路径均有测试。
