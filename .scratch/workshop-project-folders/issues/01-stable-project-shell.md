# 01：稳定项目壳与导航层级

Type: task
Status: ready-for-human
Blocked by: None

## What to build

让项目标题、面包屑、概览/美术/UI/视频导航在项目内任何页面都稳定存在,并将项目、工作区、对象和图片详情位置全部交给 URL 表达。取消“返回工坊”,使用“全部项目”和面包屑返回。

## Acceptance criteria

- [x] 从项目页面进入角色后,项目导航不增加、不消失、不改变位置。
- [x] 从角色返回、刷新和浏览器 Back 后仍恢复相同项目与工作区。
- [x] 错误项目深链纠正时保留角色槽位、Job 和图片详情子路径。
- [x] 左栏显示项目首页、文件夹、资产库的稳定入口；角色名册只属于美术视图。
- [x] 未分类角色继续可访问,不强迫新建角色先选择项目。
- [x] 桌面与移动端导航回归测试覆盖上述路径。
