# 05：视频参考联动与整体收口

Type: task
Status: ready-for-agent
Blocked by: 03, 04

## What to build

让项目视频镜头可以直接选择角色皮肤或 UI 页面定稿作为参考,复用现有 Job 记录实际参考路径、Prompt 和参数,并跑通项目文件夹的完整个人创作流程。

## Acceptance criteria

- [ ] 视频镜头参考选择器可浏览当前项目的角色、皮肤和 UI 定稿。
- [ ] 新视频 Job 保存实际使用的参考路径,历史 Job 展示不被后续定稿改变。
- [ ] “夏日版本文件夹 → 角色皮肤 → UI V2 → 宣传片”流程可完整走通。
- [ ] 项目文件夹正确混合展示三类资产,跳转后保留文件夹返回上下文。
- [ ] 废弃导航分支和重复本地导航状态被删除。
- [ ] API 契约、Skill 文档、数据校验、前后端测试、类型检查和 clean build 全部通过。
