# 02：个人项目文件夹与混合资产引用

Type: task
Status: ready-for-human
Blocked by: 01

## What to build

允许用户在项目内创建个人文件夹,并把现有角色、UI 页面和视频企划混合加入文件夹。文件夹只负责整理,不拥有资产。

## Acceptance criteria

- [x] 文件夹支持新建、重命名、排序、备注和删除。
- [x] 同一文件夹可同时展示美术、UI、视频成员。
- [x] 同一资产可出现在多个文件夹中,且始终指向同一份内容。
- [x] 从文件夹移除成员不会删除资产或历史。
- [x] 删除文件夹只删除整理关系,并有明确确认文案。
- [x] 文件夹内的概览/美术/UI/视频视图只过滤展示,不改变资产归属。
- [x] 双端契约、原子写入和文件夹 CRUD/引用测试通过。
