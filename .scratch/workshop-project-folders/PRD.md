# PRD：个人工坊资产库与项目文件夹

Status: ready-for-human

## 目标

把工坊从“项目分组下展开角色”的不稳定导航,调整为适合个人长期使用的层级：每个游戏项目固定拥有资产库,并允许创建多个项目文件夹,按版本、活动或日期混合整理美术、UI 和视频资产。

```text
游戏项目
├── 项目首页
├── 项目文件夹
│   ├── 夏日版本
│   ├── V2 组件设计
│   └── 08.22 对外宣传片
└── 资产库
    ├── 角色与皮肤
    ├── UI 方案与页面
    └── 视频企划
```

## 核心规则

- 资产始终归项目资产库所有。
- 项目文件夹只保存引用,不复制或搬动资产。
- 同一资产可以出现在多个文件夹中。
- 删除文件夹或移除成员不删除资产。
- 角色皮肤继承母角色,同时拥有完整独立流程。
- UI V1 / V2 轻量并存,不建设分支合并系统。
- 视频复用现有 Job 保存的参考路径、Prompt 和参数。

## 不做

- 工作包生命周期、里程碑、交付状态或交付快照。
- 负责人、权限、审批、排期或团队看板。
- 通用依赖图、安全删除系统或自动升级引用。
- 文件夹嵌套和 UI 分支合并。
