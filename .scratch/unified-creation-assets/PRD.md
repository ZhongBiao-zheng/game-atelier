# 统一创作资产库

## 目标

建立应用级个人创作资产库，让提示词和单张图片在创作台与全部画布项目间保持同一身份、版本历史与可恢复归档。所有内容都由用户显式保存；使用资产只改变当前创作上下文，不自动修改模板或既有引用。

## 第一版范围

- 提示词资产：标题、正文、零个或多个变量、胶囊标签、不可变内容版本。
- 图片资产：标题、单张图片、胶囊标签、不可变内容版本；相同文件按内容摘要识别重复。
- 全局视图与画布项目关系：`全部资产 / 本项目`，首次在画布使用自动加入项目关系，移出项目不删除资产或节点。
- 归档与恢复；不提供物理删除。
- 现有 Canvas 本地资产与提示词升级为全局资产并保留项目关系；Studio 历史不批量导入。
- 不包含模型、生成参数、参考素材组合、团队共享、文件夹或独立顶级资产页面。

## 提示词变量

- 保存提示词时选择正文片段并执行“设为变量”，输入变量名；所选正文成为默认内容。
- 同名变量在一次使用中共享填写值；留空使用默认内容。
- 使用时灰色变量名只是编辑提示，不进入最终正文。
- 取消变量身份保留当前文字，并与前后文无额外空格拼接。
- 用户修改已填入的提示词后立即解除资产关联，成为普通提示词草稿。

## 创作台体验

- 提示词组件右侧、发送按钮外侧提供独立圆形资产按钮。
- 资产面板是右侧非模态面板，底部停在提示词组件上方。
- 资产卡展示标题、两行预览和胶囊标签，默认最近使用优先。
- 点击卡片查看详情或填写变量；只有明确点击“使用”才替换提示词。
- 列表“使用”直接采用默认变量、关闭面板并填入；详情“使用”采用当前变量值后执行同样动作。
- 主操作替换当前提示词，更多菜单支持插入光标位置。
- 当前提示词显示保存图标；历史提示词、生成图片和上传参考图在既有更多菜单中提供保存动作。

## 画布体验

- 复用同一套资产面板、卡片与数据。
- 打开生成配置时，提示词填入当前草稿、图片成为当前参考；没有打开生成配置时分别创建文本节点或图片节点。
- 未保存内容通过“保存并加入画布”选择目标画布；完成后留在创作台，并提供前往查看链接。
- 旧引用永不静默替换。明确更新时保留同名变量值，新增变量使用默认值，已删除变量移除。
- 选中旧引用时低调显示“有新版本”；默认只更新当前引用，更多菜单可更新本画布全部引用。

## 版本与元数据

- 修改提示词正文、变量或替换图片创建新版本；修改标题、标签不创建版本。
- 恢复旧内容会复制为新的最新版本，不改变旧版本顺序。
- 新使用默认最新版本；已使用或已提交内容固定原版本。
- 图片自动标题优先取来源提示词前段，上传图片退回文件名；标题可编辑。
- 标签自由输入，Enter 创建胶囊，并提供近期标签建议；第一版不做文件夹。

## 验收

- Studio 与 Canvas 看到同一资产身份、最新版本、标签和归档状态。
- 所有保存均为用户显式动作，没有后台自动入库。
- 任何既有节点、草稿或生成历史都不会因资产更新而静默变化。
- 图片重复保存会要求用户确认复用；提示词重复只提醒。
- 第一版升级后不再保留可独立编辑的 Canvas 本地资产/提示词模型。
