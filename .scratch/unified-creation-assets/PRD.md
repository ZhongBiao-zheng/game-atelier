# 统一创作资产库

## 目标

建立应用级个人创作资产库，让提示词和单张图片在创作台与全部画布项目间共享同一份当前内容。资产只在
用户明确保存时创建；使用资产是一次复制，绝不自动入库、自动更新或建立可回写引用。

## 第一版范围

- 提示词资产：标题、正文、零个或多个变量、胶囊标签、一份当前内容。
- 图片资产：标题、单张当前图片、胶囊标签；相同文件按 SHA-256 识别重复。
- 全局视图与画布项目关系：`全部资产 / 本项目`；在画布使用时自动加入项目关系。
- 原位编辑与经过二次确认的物理删除；不提供版本、归档、恢复或更新引用。
- 现有版本化资产执行一次性备份迁移；Studio 历史不批量导入为资产。
- 不包含模型、生成参数、参考素材组合、团队共享、文件夹或独立顶级资产页面。

## 提示词变量

- 保存提示词时选择正文片段并执行“设为变量”，输入变量名；所选正文成为默认内容。
- 同名变量在一次使用中共享填写值；留空使用默认内容。
- 使用时灰色变量名只是编辑提示，不进入最终正文。
- 取消变量身份保留当前文字，并与前后文无额外空格拼接。

## 列表与详情

- 提示词组件右侧、发送按钮外侧提供独立圆形资产按钮。
- 资产面板是右侧非模态面板，底部停在提示词组件上方。
- 资产卡只展示标题、两行预览和胶囊标签；点击卡片进入详情，不提供卡片快捷使用。
- 详情只提供主操作“使用”和次操作“编辑”。提示词有变量时先在详情填写；留空用默认内容。
- 点击“使用”立即关闭资产窗口并把内容复制到当前提示词/画布上下文，不再有第二步。

## 编辑与删除

- “编辑”编辑资产本身，Studio 与 Canvas 采用同一套编辑器。
- 提示词编辑字段：标题、提示词正文、变量与默认内容、标签。
- 图片编辑字段：当前图片、可选替换图片、标题、标签。
- 保存后返回该资产详情；同一个 `asset_id` 原位更新，不产生版本。
- 编辑未保存时返回或关闭，必须选择“放弃修改”或“继续编辑”，绝不自动保存。
- 删除入口只在编辑页底部；确认弹窗展示资产标题和“删除后不可恢复”，确认后物理删除。

## 使用与来源快照

- Studio 使用提示词资产时替换整个提示词；Canvas 有生成草稿时替换草稿，没有时创建内容节点。
- 图片资产在 Studio 成为参考图片，在 Canvas 成为参考节点或新图片节点。
- 使用时复制当前内容并完全断开；后续编辑、重命名或删除资产不影响任何既有使用结果。
- 生成历史和 Canvas 节点详情只弱显示冻结的 `来源：资产标题`；来源名不进入提示词正文、不可点击，
  且永不随资产变化。

## 迁移

- v1 目录迁移前，完整备份 `creation-assets/` 和会被改写的 Job/Canvas 文件到时间戳目录。
- 每个资产只保留最新内容；旧归档资产恢复到主列表。
- 已有 Job 和 Canvas 内容保持冻结正文/媒体，并在可解析时回填来源标题快照。
- v2 运行时不包含版本/归档业务路径，也不会读取迁移备份。

## 验收

- Studio 与 Canvas 看到同一资产身份、当前内容和标签。
- 所有保存均为用户显式动作，没有后台自动入库或自动保存。
- 列表卡无快捷使用，详情无版本、归档、编辑信息、移出项目或更新引用。
- 编辑同一资产不改变 `asset_id`；删除后 API 与 UI 均无法恢复。
- 任何既有节点、草稿或生成历史都不会因资产更新或删除而变化。
- 图片重复保存会要求用户确认复用；提示词重复只提醒。
