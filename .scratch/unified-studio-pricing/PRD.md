# 创作台统一计价器

## 目标

创作台在提交图片或视频时，对已核实价目计算人民币预计费用并冻结到 Job；生成成功后，在历史记录的“耗时 · 时间”一行最右侧展示。未核实价格的渠道、模型或参数不写费用，也不显示占位提示。

## 范围

- 统一以真实渠道、协议、模型和本次生成参数计算预计费用。
- 支持已核实价目的 OpenAI-HK 图片、火山 Ark Seedream / Seedance、阿里百炼 HappyHorse。
- 转售渠道只使用自身已核实价目；TokenDance、Tuzi 等无法可靠推导时不展示费用。OpenRouter 优先使用成功响应返回的真实美元费用，只有缺少真实费用时才按官方 SKU 估算。
- 图片费用乘以生成张数；视频费用按对应厂商规则乘以时长、输出规格和生成条数。
- Seedance 仅在分辨率、比例和时长可确定，且没有未知时长的参考视频时计算。
- 完整创作台与首页紧凑创作台共用同一提交计价入口。
- 提交时将可确定的预计费用写入 `params.estimated_cost_cny`；OpenRouter 等返回真实账单费用的渠道在成功后写入实际费用快照，历史优先显示实际费用。旧任务不按当前价目动态回算。
- 输入区不显示提交前价格；历史金额统一以 `¥ 10.11` 样式显示，最多两位小数且不补无意义的零。
- 本功能不是厂商实际账单，不实现余额查询、扣费对账或用户自定义价目。

## 验收标准

1. 已核实价目的生成任务在提交时保存人民币费用快照，未核实价目不保存费用字段。
2. 同模型经不同渠道调用时不会错误复用官方直连价格。
3. 完整创作台与首页紧凑创作台使用同一计价规则，图片和视频均覆盖。
4. 成功历史在耗时/时间行最右侧显示 `¥ **.**`；无法计算、旧任务无快照时不显示。
5. 历史展示只读取提交快照，价目更新不会改变旧记录。
6. 已核实价格、渠道防串价、格式化、费用冻结与历史显隐均有自动化测试。
7. 删除旧的 OpenAI-HK 专用计价入口，只保留统一计价器。

## 价格来源

- 火山方舟产品定价页，2026-08-27 核对。
- 阿里云百炼模型定价页，2026-08-27 核对。
- OpenAI-HK 与 Tuzi 由用户按实际渠道账单确认，2026-08-28 核对。
- OpenRouter Image / Video Models API 与生成响应文档，2026-08-28 核对。

## 统一换算

- 只有美元报价需要换算时，固定使用 `1 USD = ¥7`。
- 汇率不联网、不动态更新；提交时折算成人民币并冻结到 Job。

### OpenRouter

OpenRouter 的图片与视频成功响应均可返回 `usage.cost`，单位为 USD；这是本次请求实际扣费，应作为历史费用的首选来源，按固定汇率乘以 7 后保存人民币实际费用快照。不得仅凭模型名套固定价，也不得用当前价目动态改写已完成任务。

当响应缺少 `usage.cost` 时，才允许使用提交时抓取并冻结的官方 SKU 估算。官方价格发现端点：

- 图片模型：`GET /api/v1/images/models`；按模型的 `endpoints` 地址读取实际端点的 `pricing[]`。
- 视频模型：`GET /api/v1/videos/models`；读取模型的 `pricing_skus`。
- 如响应给出 generation id，可用 `GET /api/v1/generation?id=...` 查询 `total_cost`、`provider_name` 与媒体 Token 等元数据。

## 已知边界

- 一般渠道费用是提交时预计值，不代表厂商最终账单；OpenRouter 成功响应的 `usage.cost` 是实际费用。失败任务不能靠预计值判断是否真实扣费。
- 旧 Job 默认不在运行时动态重算；已核实渠道可执行一次性、可备份的快照回填。
- 新增渠道或模型必须先核实自身价格与协议，再加入白名单和测试。
