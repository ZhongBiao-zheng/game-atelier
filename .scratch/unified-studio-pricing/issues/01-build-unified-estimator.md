# 01 — 建立统一生成计价器

- Type: feature
- Status: completed
- Blocked by: none

## 工作

- 用纯函数统一图片与视频提交费用计算，并按渠道、协议、模型和参数严格匹配。
- 完整创作台与首页紧凑创作台在创建 Job 前共用同一计价入口。
- 将可核实的人民币预计费用冻结到 `params.estimated_cost_cny`。
- 历史记录只读取费用快照，在耗时/时间行最右侧按 `¥ **.**` 展示。
- 未核实聚合商、未知价格参数和没有快照的旧任务不展示费用。
- 输入区不再展示价格，删除旧 `creditCost.ts` 专用入口。

## 验证

- 计价规则、渠道防串价和金额格式化单测。
- 完整创作台与首页紧凑创作台的提交快照测试。
- 历史费用位置、最多两位小数和不可计价隐藏测试。
- 前端类型检查、完整测试、production clean build 与三平台 CI。
