# 03 — 探测 TokenDance 实际计费用量

- Type: investigation
- Status: pending
- Blocked by: authorized real generation test

## 目标

通过一笔可控的小规格 TokenDance Seedance 真实任务，确认提交响应、轮询响应与终态响应是否包含：

- 实际路由服务商（火山方舟 / 特工宇宙或稳定标识）。
- 实际输出 Token 数量或可复算所需的输出尺寸、帧率、时长。
- 实际金额、单价、促销标记或账单 ID。

## 约束

- 未得到用户开始测试的明确指令前不发起付费任务。
- 日志与调查记录不得保存 access key、请求签名或其他凭证。
- 使用最低可用分辨率和最短时长，且只提交一条任务。
- 调查前后记录 TokenDance 后台账单，用任务 ID 对齐，不用时间近似猜测。

## 验收

- 给出实际响应字段的脱敏样本及其所在阶段。
- 能确定费率时，明确“提交时估算”还是“完成后按实际用量回写”。
- 不能确定时继续隐藏价格，不默认取最低、最高或某个服务商费率。
