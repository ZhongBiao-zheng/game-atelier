# 02：顶级画布入口与项目卡片墙

Type: feature

Status: ready-for-human

Blocked by: 01

## Scope

- 在创作台和工坊之间增加“画布”顶级导航。
- 实现 `/canvas` 项目卡片墙、新建卡、自动封面、最近编辑排序和重命名。
- 保持 `/studio` 与 `/workshop` 路由和行为不变。

## Acceptance

- 导航顺序、激活态和移动端横向容纳正确。
- 新建项目立即进入空画布；返回后卡片信息正确。
- 无媒体项目显示中性占位，封面不保存第二份漂移路径。
- 不出现 Skill、工坊项目或 Studio 历史的自动导入入口。
