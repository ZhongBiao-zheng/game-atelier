# PRD：独立画布项目与无限画布

Status: ready-for-human

## 目标

在“创作台”和“工坊”之间增加独立的“画布”顶级功能区。用户先在卡片墙中手动创建画布项目，再进入沉浸式无限画布，人工添加文本、资源和生成节点，指定参考并发起图片或视频生成。

## 核心规则

- 顶栏顺序为“主页 / 创作台 / 画布 / 工坊”；创作台与工坊保持现状。
- `/canvas` 是画布项目卡片墙，`/canvas/:id` 是沉浸式编辑器。
- 画布项目只能由用户在 Web UI 中创建，Skill 不创建、不填充、不推进。
- 每个项目独立拥有画布文档、上传资源和 `namespace="canvas"` 的 Job。
- React Flow 只负责画布机械层，现有 Job Runner 仍是共享的唯一底层执行器。
- 来源连接表达人工指定的参考，不触发整图执行或下游节点。

## 用户路径

```text
/canvas 项目卡片墙
  → 新建或打开画布项目
  → /canvas/:id 沉浸式画布
  → 手动创建文本 / 图片 / 视频 / 音频资源节点
  → 手动绑定参考并编辑生成节点
  → 点击生成
  → SSE 在原节点更新结果
```

## 验收规则

- 多个画布项目可新建、打开、切换和重命名，卡片有自动封面与最近编辑时间。
- 项目页包含左上项目切换、左侧节点工具条、中央无限画布和左下小地图。
- 节点、来源边和 viewport 自动保存并可在刷新后恢复。
- 画布 Job 使用独立 namespace 与输出目录，状态跟随现有 Job/SSE。
- 移动或连接节点不自动运行；Skill 不会产生画布项目或节点。
- 375、768、1440 可用，150 个媒体节点下基本操作无明显卡顿。
- 双端 schema、API 文档、设计规范和自动化验证同步收口。

## 不做

- Skill 自动创建、填充或运行画布项目。
- 与 Studio/工坊项目自动同步或自动关联。
- 整图执行、拓扑调度、分支、循环和子图。
- 社区、积分、分享、3D、剪辑时间线、3D 片场、图片编辑器。
- 无恢复机制的项目永久删除。
