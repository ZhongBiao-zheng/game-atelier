# 01：删除项目文件夹

Type: refactor

Status: completed

Blocked by: none

## What to build

从工坊导航、页面、路由、API 和领域契约中完整删除项目文件夹，使用户直接通过项目首页、角色、UI 和视频管理内容。

## Acceptance

- 左侧不再显示文件夹标题、新建入口或文件夹列表。
- 文件夹页面和深链不再参与路由，旧地址落到项目首页或明确的不存在状态。
- 文件夹 CRUD、引用关系、返回上下文和活动时间计算全部删除。
- 角色、UI、视频的创建、改名、删除与跳转不再维护文件夹引用。
- 后端 Schema、API 契约、前端类型、测试和发布文案没有文件夹功能残留。
- 已有 `folders.json` 不自动删除，运行时代码不再读取。
