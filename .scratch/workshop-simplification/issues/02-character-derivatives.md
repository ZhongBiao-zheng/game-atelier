# 02：将角色皮肤重构为平级角色衍生

Type: feature

Status: completed

Blocked by: 01

## What to build

用户可以从一个角色发起“创建衍生”，以当前角色定稿或其他图片作为冻结来源，建立一个平级、独立、拥有完整美术流程的新角色资产。

## Acceptance

- 所有“皮肤 / 母角色 / 角色变体”用户文案改为“角色衍生 / 来源角色 / 来源素材”。
- 创建入口打开响应式 Dialog，不在侧栏内联展开或产生横向溢出。
- 创建只要求衍生名称，不再要求填写差异描述。
- 默认包含当前角色可用定稿，也可选择项目作品图片或上传本地图片。
- 来源素材复制进新角色的来源目录，后续来源角色变化或删除不影响衍生角色。
- 衍生角色在角色列表平级展示，可继续被其他衍生引用，不形成嵌套树。
- API、双端 Schema、Skill 上下文、删除/改名逻辑和测试使用新契约，不保留旧 variant 路径。
