# 03：精简项目导航与项目经验高度

Type: fix

Status: completed

Blocked by: 01

## What to build

项目导航使用最短、直接的资产标签，并限制长篇项目经验的默认阅读高度，让用户进入首页即可看到作品画廊。

## Acceptance

- 项目导航只显示“项目首页”“角色”“UI”“视频”。
- 所有对应标题、空状态和可访问名称使用一致术语。
- 项目经验短内容保持自然高度，长内容默认在约 288px 内滚动。
- 阅读区支持鼠标、触控和键盘滚动，焦点可见且没有横向溢出。
- 375、768、1440 三档进入首页都能在合理首屏范围看到画廊入口。
