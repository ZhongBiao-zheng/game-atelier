# 三视图与角色设定表

来源等级的含义见 prompt-method。项目规范里有版式要求的，以规范为准。

## 默认
- 画幅：16:9 横版。
- 纯色背景（中性灰或白），平光，不加场景和氛围光。
- 同一角色的一致性要求写在版面内容之前。

## 版面
用文字逐区描述，不要拿别的角色的设定板当版式参考图：参考图里他人的五官和部件会被搬过来，否定词压不住。[实测]

常用版面：
- 三视图：正面、侧面、背面，同比例、同服装、脚底水平对齐。
- 设定板：左侧三视图，右侧表情特写 3 到 4 个，下方道具和配色细节。
- 给视频模型用的角色表：大尺寸的四分之三侧脸肖像、正面全身、背面全身三格。

## 必写
1. 身份与外观拆解（没有角色参考图时）。有参考图时只写「按图1 的角色」，不重写外观。
2. 每个视图的内容和位置，格数写死。
3. 「同一角色，同比例，同服装，水平对齐」。
4. 左右不对称的部件（尾巴、斜戴的帽子、单侧肩甲、围巾流苏），在背面一条写明：「角色转身 180 度，正面在画面右侧的 X，背面视图中位于画面左侧」。只写「背面」时模型会照抄正面的左右位置。[实测]
5. 画面里的标注文字用用户原文；没有要求就写「不添加任何文字」。

## 骨架
```
[用途：角色设定板，16:9，纯色背景] + [一致性锁] + [逐区版面：位置 + 视图 + 内容] + [不对称部件的背面位置] + [画风与线条] + [文字约束]
```

## 给视频模型用的角色表
- 正面全身那一格去掉头部。远景里模型会从全身小图取脸，那张脸又小又糊；去掉后只能从特写取脸。写法：「隐形人台，没有脖子没有头，领口上方直接是灰色背景，这一格不能画出头部和脸」。[实测]
- 质感用中性灰背景、平光、真实皮肤。不加胶片颗粒、电影镜头和调色，否则角色进新场景时对光线不响应。[社区，待复核]
- 湿身、受伤、换装各做一张表，不在一张表里混写状态。
- 提示词里不写年龄数字，用身份、服装、体型描述。写到未成年会让视频模型的内容过滤变严。
- 目标视频模型会拦截可辨识的写实真人脸时，改用非写实画风。

## 多个年龄段或状态
先出一个基准版本并选定，其余版本附基准图生成，五官才能一致。[实测]

年龄的差别用骨相、体型、发色来写，同样不写数字：晚年版写「颧骨突出、眼窝深陷」，只写「消瘦、白发」不够；少年版只写「娃娃脸、稚气」仍会偏成熟，要补体型（个子矮小、肩膀窄）。[实测；少年版的补法未验证]

## 出图后看什么
设定板必须放大逐区看，整图缩略看不出问题：[实测]
- 三个视图是否同一个角色、同比例。
- 不对称部件在背面的左右位置。
- 表情特写里有没有多余的嘴线。
- 标注文字有没有错字。
