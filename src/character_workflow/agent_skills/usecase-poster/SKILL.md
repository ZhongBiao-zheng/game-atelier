# 海报与美宣

来源等级的含义见 prompt-method。

## 默认
- 画幅：竖版 2:3 或 3:4；横版 KV 16:9；社媒封面按平台（小红书 3:4，抖音 9:16，B 站 16:9）。
- 单张成品，不要拼贴和方案板。

## 必写
1. 第一句声明类型：「游戏美术宣传海报，角色 KV，3:4」。模型会更快进入海报的创作模式。[实测]
2. 主视觉到底是什么：一个主体、一个姿态、一件核心道具。
3. 版式结构：居中、左对齐、对角线、上图下字，选一种。
4. 标题区的位置与留白。
5. 标题与副标题的原文（用户给了才写）。
6. 主色加辅色。

## 骨架
```
[类型与画幅] + [主视觉：主体、姿态、核心道具] + [场景与氛围] + [版式与文字层级] + [配色] + [光影质感] + [约束]
```

## 文字怎么处理
- 用户给了标题原文：加引号写死，写字体气质、位置、层级，写「只出现一次，不添加其他文字」。
- 用户没给文字：写「图内不生成任何文字，顶部留出标题空间」。后期排字更稳。
- 字数多、要求精确时，选文字能力强的模型；Midjourney 不承担文字。

## 反默认
- 主体占画面五到七成。
- 道具当作构图骨架来写：写它的角度和在画面里的走向。
- 不要杂乱拼贴，不要多个同等重要的主体。
- 有冲击力的写法：对角线构图，强明暗，一个高饱和强调色。

## 有角色参考图时
文字只写氛围、动作、构图，不重写角色外观。[实测]

## 社媒封面
- 标题比副标题大 3 倍以上，文字区和人物区分开，文字不压脸。
- 一张封面只讲一个点，字数控制在 12 个字以内。
- 高饱和、高对比，人物表情放大。

## 出图后看什么
- 标题区是否留出、主体是否压到标题区。
- 文字是否与原文逐字一致。
- 有没有混进多余的文字、logo、水印。
