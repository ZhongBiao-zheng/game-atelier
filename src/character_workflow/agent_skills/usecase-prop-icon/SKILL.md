# 道具与图标

来源等级的含义见 prompt-method。本节多为通行做法，未在本产品实测。项目规范里有图标规范的，以规范为准。

## 默认
- 画幅 1:1。
- 单个物体居中，四周留出一到两成的边距。
- 背景：纯色，或用透明背景参数（模型支持时）。
- 不加文字、数字、边框，除非用户要。

## 必写 [通用]
1. 物体是什么，以及它的一个识别特征（缺口的刀刃、发光的符文、缠着布条的握柄）。
2. 视角：道具常用四分之三俯视；技能图标常用正视的符号化构图。
3. 材质分区：金属、木、皮革、宝石分别在哪。
4. 光源：单一方向（常用左上），同一套图标保持一致。
5. 画风：厚涂、扁平、像素、写实渲染，与项目一致。
6. 轮廓：外形清晰，缩小到很小时仍能认出。写「轮廓完整，不被裁切」。

## 骨架
```
[用途：游戏道具图标，1:1，纯色背景] + [物体与识别特征] + [视角] + [材质分区] + [光源方向] + [画风] + [约束：单个物体、居中、留边、无文字]
```

## 成套图标
- 一致性锁写在列表之前：同一视角、同一光源方向、同一描边粗细、同一饱和度范围、同一背景。
- 两种做法：
  - 一张图里排网格：写行列数和总数，逐格列出物体。适合快速出一套草稿。
  - 逐张生成：先出一张定稿，后面每张附它作画风参考，写「只取画风、光源和描边，不复制其中的物体」。适合要单独交付的图标。
- 稀有度或等级用颜色和光效强度区分，写清每一级的差别。

## 应用图标
和道具图标不同，目标是在一屏图标里第一眼被看见：
- 一个拟人化或强识别的主体，细节少。
- 主体与背景的颜色对比拉大；主体不够突出时加描边和投影。
- 可以用倾斜裁切，让主体从画布一侧探出一部分。
- 不写文字。

## 反默认
- 不要把物体放进场景里，不要手持。
- 不要多个物体堆在一起（成套网格除外）。
- 不要强透视和景深虚化，物体整体清晰。

## 出图后看什么
- 是否只有一个物体、是否居中留边、轮廓是否完整。
- 成套时每格的视角、光源、描边是否一致，数量是否对。
- 背景是否干净到可以抠图。
