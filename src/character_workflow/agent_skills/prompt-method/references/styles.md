## 1. 风格配方写法

一个风格写成 5 部分，缺任一部分都容易跑偏：

1. **命门**：3–5 个让人一眼认出这个风格的可见特征。
2. **色板锁**：允许的颜色（最好带 HEX）和禁止的色相。
3. **媒介与笔触**：工具、线条性质、纸张或底材。
4. **反默认**：模型做这个风格时最常出的错，写成硬性约束。
5. **验证**：在哪个模型上实测有效。

把风格当一整套成像条件，不当滤镜。例：港式复古的成立条件是"强直闪 + 低解析 DV 传感器 + 中度过曝 + 抬高黑位 + 高光晕染 + 暖脏偏色（高光微黄、中间调粉灰、阴影青绿）"，先在成像阶段牺牲信息，再谈美感；只写"偏黄 + 颗粒"只会得到一张发灰的照片。

示例配方：

- **水墨写意**：命门＝墨分五色（焦浓重淡清）、飞白枯笔、宣纸渗化墨晕、大量留白、一角朱红印章。色板＝黑墨为主，至多淡赭石或花青点染。反默认＝不要均匀灰度数字滤镜、平滑渐变、卡通描边、艳色铺底；默认只盖印不题字，避免伪汉字。
- **吉卜力式动画**：命门＝单一焦点、简化背景、大块平滑水彩渐变、少而整的大朵云、柔和暖光。反默认＝不写 lush / detailed（在 GPT Image 上会出零碎云朵和斑驳纹理）。
- **暖色扁平绘本**：命门＝圆润几何大色块、几乎无外轮廓线（形体靠色块相接）、每个色块最多一深一浅硬边阴影、约七成留白。色板＝深藏青、雾蓝、珊瑚橙、金橙、暖米白底，禁止其他色相。反默认＝不要圆脸大头萌系比例、渐变体积、3D。
- **复古电影海报**：命门＝手绘喷枪质感、强透视人物群像、大字片名、半调网点、纸张泛黄折痕。

## 3. 导演与摄影美学特征

写特征，不只写名字（只写名字容易照搬代表作构图）。可以"名字 + 特征"一起写。

## 4. 插画与传统媒介

- **水性**：透明水彩（晕染、水渍边、留白纸）· 水粉 gouache（不透明、干刷颗粒）· 淡彩速写（墨线 + 薄涂）
- **干性**：铅笔素描（排线、明暗五调子）· 炭笔 · 彩铅 · 蜡笔（蜡质笔触、露白）· 圆珠笔缠绕线
- **数字**：赛璐璐平涂 · 厚涂 · 扁平矢量（统一描边、无渐变）· 像素（统一方块、有限调色、无抗锯齿）· 低多边形
- **印刷**：丝网印刷 · Risograph 孔版（套色错位、颗粒）· 木刻 / 版画（刀痕）· 半调网点 · 拼贴
- **东方**：工笔重彩（勾线填色、矿物色）· 写意水墨 · 敦煌壁画（土黄赭石底、斑驳肌理、石青朱砂）· 青花瓷绘（钴蓝 + 米白单色）· 浮世绘（平面色块、粗轮廓、波浪纹样）· 年画 · 剪纸 · 刺绣（针脚肌理、丝缎光泽、金线）
- **手工质感**：纸雕（层叠厚纸、柔和投影）· 毛毡（纤维毛边）· 黏土定格 · 折纸 · 毛线编织

## 5. 3D 与材质

- **渲染路线**：C4D / Octane（干净商业感）· Blender Cycles · Unreal Engine 5（实时写实、Lumen 光照）· 黏土渲染（白模）· 等距 isometric 微缩
- **材质词**：哑光 PVC · 软胶 vinyl · 树脂（锐高光）· 磨砂玻璃 · 琉璃 / 珐琅 · 熔融金属 · 拉丝钢 · 碳纤维 · 次表面散射（皮肤、玉、蜡）· 天鹅绒 · 风化木材 · 清水混凝土 · 大理石
- **规则**：每张图选 1–2 个主材质；材质写制造方式（注塑、浇铸、手工缝制）比写形容词更稳。

## 6. 色板

原则：冷暖对冲强于同色系渐变；高饱和 + 无彩色（黑、白、灰）显得贵；主色约 60%、辅色 30%、点缀 10%。

| 场景 / 情绪 | 配色 |
|------------|------|
| 古风宫廷 | 朱红 × 玄黑 × 暗金 |
| 盛唐华服 | 孔雀蓝 × 暗金 × 米白 |
| 古装夜景 | 低饱和青蓝 × 琥珀金 |
| 乡土现实 | 赭土棕 × 羊毛乳白 × 暗绿 × 深红 |
| 科幻太空 | 冷钢蓝 × 深海蓝 × 银白 × 少量锈红 |
| 废土末日 | 灰褐 × 煤黑 × 沙尘米 × 暗红点缀 |
| 赛博夜景 | 品红 × 青 × 深紫黑（容易泛滥，至多作点缀） |
| 欧洲建筑 | 克莱因蓝 × 纯白 |
| 沙漠异域 | 赤陶 × 祖母绿 × 香槟金 |
| 日系清新 | 奶白 × 薄荷绿 × 浅木色 |
| 孤独 | 冷灰蓝 + 一处暖橙点光 |
| 温暖 | 琥珀 × 奶油 × 木棕 |

## 7. 构图手法

| 手法 | 写法 | 适合 |
|------|------|------|
| 视线阻断 | 透过[书架/雨窗/树叶/百叶窗]的缝隙看主体，前景虚化遮挡 30–50% | 暗恋、监视、窥探秘境 |
| 极端裁切 | 主体[额头/半脸/下巴]出框，只留[眼鼻唇]，脸占 90% | 杂志封面、角色海报 |
| 框中框 | 门框、窗框、拱门、镜子框住主体 | 古风、叙事、孤独 |
| 引导线 | 铁轨、道路、廊柱、光束汇聚到主体 | 纵深、方向感 |
| 前景遮挡 | 前景虚化的人物肩部、花枝、灯笼 | 电影感、层次 |
| 对称 | 严格中心对称，正面平视 | 仪式感、韦斯·安德森 |
| 负空间 | 主体占 10–20%，其余为天空/墙/水面 | 孤独、高级、留标题 |
| 低角度仰拍 | 机位贴地 15–30 度向上 | 英雄感、权威 |
| 鸟瞰 / 上帝视角 | 正上方垂直俯拍 | 图案感、城市、平铺 |
| 荷兰角 | 画面倾斜 10–20 度 | 紧张、失衡 |
| 过肩 | 越过前景人物肩膀看对象 | 对话、对峙 |
| 尺度反差 | 极小人物 vs 巨大建筑/自然 | 史诗、震撼 |
