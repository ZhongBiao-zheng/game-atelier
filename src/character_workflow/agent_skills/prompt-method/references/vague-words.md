# 模糊词翻译表（完整）

同一句里出现多个模糊词时，选一个当主调，其余当辅助，不要全部展开叠加。

| 模糊词 | 展开成 |
|---|---|
| 高级感 | 不超过 3 色的克制色板，四成以上负空间，大面积柔光，只突出一种主材质，去掉装饰元素 |
| 电影感 | 宽画幅（2.39:1 或 16:9），有动机的光源（画面内可见的灯、窗、火），前中后景层次或前景遮挡，浅景深，统一调色，胶片颗粒 |
| 氛围感 | 体积光或薄雾，逆光或侧逆光，空气透视，一个情绪光源（灯笼、霓虹、窗光） |
| 故事感 | 一个正在发生的动作，一个视线方向或悬念道具，环境里的使用痕迹 |
| 真实、质感 | 材质瑕疵（毛孔、雀斑、划痕、灰尘、褶皱），物理交互（雨打金属、风吹面料），非棚拍的自然光；摄影类直接写「真实照片」 |
| 大片感、史诗 | 低机位仰拍，人小景大的尺度反差，逆光剪影，体积光束，超广角或长焦压缩 |
| 震撼 | 极端视角（虫视、鸟瞰、荷兰角），巨大尺度对比，单一强光源 |
| 清新、日系 | 高调轻微过曝，低反差，抬高阴影，偏青绿，窗光逆光，细颗粒 |
| 复古 | 指定年代和媒介（90 年代港片 DV、早期 CCD 卡片机直闪、丝网印刷），不写「复古滤镜」 |
| 温暖、治愈 | 3000 到 4000K 暖色温，柔和大光源，木、布、陶等自然材质，一个安静的日常动作 |
| 酷、帅 | 低角度，硬侧光，高反差，偏冷，主体不看镜头 |
| 可爱 | 圆润几何，大头小身比例，软材质（绒、软胶），粉彩色，表情放大 |
| 梦幻 | 柔焦，光晕或高光溢出，低饱和粉紫或珍珠白，漂浮粒子 |
| 孤独 | 小主体，大负空间，冷色，单一光源，对称或空旷构图 |
| 热闹 | 多层人群，暖色点光源，深景深，饱和暖色 |
| 科技感 | 冷白或冷灰基调，精确点光源，玻璃或拉丝金属材质，网格或光线引导；不默认堆蓝紫霓虹 |
| 国风、东方 | 指定朝代，具体器物纹样与建筑构件，留白，矿物色（朱砂、石青、赭石、藤黄） |
| 简约 | 单主体，纯色或渐变背景，五成以上负空间，不超过 2 色 |
| 有冲击力（海报） | 主体占画面五到七成，对角线构图，强明暗，一个高饱和强调色 |
| 好看点、优化一下 | 先查五维哪一维缺失（通常缺光源动机或色板），只补缺的那一维 |
