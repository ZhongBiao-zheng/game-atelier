# 图像提示词通用写法

底稿：image-prompt 技能（2026-10 版）。条目的来源等级：[官方] 厂商文档；[社区] 公开教程与评测；[实测] 实际出图对比过；[通用] 行业通行做法，未在本产品实测。实测结论优先于社区条目。

核心判断：模型读的是可见的物理条件。形容词描述的是观众的感受，提示词要写的是产生这种感受的光源、镜头、材质和构图。

## 1. 顺序与五维

顺序：用途/类型 → 主体置景 → 美学调性 → 镜头光学 → 色彩光影 → 质感后期 → 约束。用途放第一句，最重要的内容放前三分之一。

| 维度 | 写什么 | 不写什么 |
|---|---|---|
| 主体与置景 | 空间位置、核心元素、材质细节、正在发生的动作 | 「一个很有意境的女孩」这类主观长句 |
| 美学调性 | 类型标签、时代、时段（历史剧、约唐代、黄昏） | 唯美、高级感、氛围感 |
| 镜头与光学 | 景别、机位、焦段、景深、构图结构 | 只写「特写」「远景」 |
| 色彩与光影 | 主光源的物理来源与方向、辅光、明暗反差、3 到 4 色色板 | 「光线柔和」「阳光明媚」 |
| 质感与后期 | 颗粒、高光溢出、体积光、渲染方式 | 超高清、神作、8K、masterpiece |

品类映射：
- 插画与画风：镜头换成「构图与视角」，质感换成「媒介、笔触、纸张」。
- 平面设计（海报、UI、图标）：加一维「版式与文字」，写分区、层级、文字原文、位置、留白比例。
- 3D 与产品：质感换成「材质与渲染」。

画幅、张数、分辨率走生成参数，不写进提示词正文。

## 2. 模糊词翻译

用户给的形容词要展开成物理条件。一句里有多个模糊词时，选一个当主调，其余只作辅助。常用的几条：

| 模糊词 | 展开成 |
|---|---|
| 高级感 | 不超过 3 色的克制色板，四成以上负空间，大面积柔光，只突出一种主材质 |
| 电影感 | 宽画幅，画面内可见的光源，前中后景层次或前景遮挡，浅景深，统一调色 |
| 氛围感 | 体积光或薄雾，逆光或侧逆光，一个情绪光源（灯笼、霓虹、窗光） |
| 真实 | 材质瑕疵，物理交互，非棚拍的自然光 |
| 史诗、震撼 | 低机位仰拍，人小景大的尺度反差，逆光剪影，体积光束 |
| 可爱 | 圆润几何，大头小身，软材质，粉彩色，表情放大 |
| 国风 | 指定朝代，具体器物与纹样，留白，矿物色 |
| 好看点 | 先查五维里缺哪一维（通常缺光源或色板），只补缺的那一维 |

完整的 20 条见 `references/vague-words.md`。画风、胶片、光位、色板、构图手法的词库见 `references/styles.md`。

## 3. 反默认

模型没有约束时会回到下面这些默认值。按品类挑相关的写成明确约束：

1. 居中摆拍、正对镜头 → 写机位角度、视线方向、主体在画面里的位置。
2. 塑料皮肤、完美对称 → 写皮肤纹理、轻微不对称。
3. 均匀照明 → 写主光方向和明暗反差。
4. 背景塞满 → 写单一焦点、负空间比例。
5. 文字乱码或擅自加字 → 文字原文加引号，写「不添加其他文字」。
6. 没有事件的风景 → 写一个正在发生的动作。
7. 细节堆砌导致画面碎 → 不写 lush、intricate、highly detailed；写「大色块、少而整的元素」。
8. 只写艺术家名字会照搬代表作构图 → 写「名字加可见特征」。画风流派名可以点名一次，后面跟命门特征。
9. 多张参考图互相污染 → 每张图一个职责，写明不复制的部分。
10. 时代错乱 → 写具体朝代，加「无现代元素」。
11. 出成拼贴或方案板 → 写「单张成品，不要网格、样机、说明文字」。
12. 手和肢体出错 → 写手的具体动作和可见范围，必要时裁掉手。

## 4. 写法规则

- 复杂需求用标签分段，一段只管一维。
- 风格锚点不超过 2 个。要混合就写配比或写「用 A 的用光融合 B 的构图」。
- 数量写死：人数、格数、道具数。
- 位置坐标化：左三分之一、顶部两成留给标题、主体占画面五到七成。
- 颜色写用途：哪一处是唯一的视觉焦点色。主色不超过 4 种。
- 写物理交互：雨打金属、风吹面料、灰尘浮在光束里。
- 画面文字：用户原文加引号，写字体气质、层级、位置，写「只出现一次、拼写完全一致」。长段正文不交给模型，只写死标题。
- 负面约束的写法因模型而异，见对应的 model-* 技能。

## 5. 参考图

一张图只承担一个职责：身份、画风、构图或姿势、产品、场景、色调。写法：

```
图1 是人物身份参考：保持面部特征、发型、体型一致。
图2 是画风参考：只取线条、配色、笔触和光影，不复制其中的人物、服装和构图。
```

- 按参考图传入的顺序称图1、图2。
- 能用 2 张不用 4 张，参考越多越容易互相污染。[实测]
- 有身份参考图时文字越短越听话：删掉外观罗列，文字只写氛围、动作、构图。[实测]
- 不把另一个角色的成品图当版式参考，版式用文字逐区描述；参考图里他人的五官会被搬过来。[实测]

## 6. 改图

- 写两张清单：改动清单（只把背景换成雪山）和保留清单（人物、姿势、服装、光线方向、构图、画幅保持不变）。多轮修改每轮都重写保留清单。
- 改材质时锁几何；改几何时写明解锁哪个区域和幅度（鼻子缩小约两成，其余五官不变）。
- 合成要写谁放在哪、比例、透视、光线方向、接触阴影。
- 风格转换拆成 6 项逐项写「保持」或「改为」：媒介、线条、色彩、光影、纹理、构图。
- 已经对了八成的图，在它上面改剩下的两成，不整张重出。

## 7. 出图后的检查与归因

先看客观项：尺寸与比例、指定文字、主体与数量、参考图是否体现、有无明显崩坏。带表情特写或小字的图要放大局部看，整图缩略看不出细线残留和错字。[实测]

发现问题时先归因，再决定改哪一处：

| 症状 | 常见原因 | 改法 |
|---|---|---|
| 画面乱 | 没有单一焦点，细节词太多 | 删元素，写主焦点和负空间比例 |
| 塑料感 | 缺材质瑕疵，光太均匀 | 加纹理与瑕疵，写有方向的光 |
| 画面平 | 没有前中后景 | 加前景遮挡、景深、空气透视 |
| 风格不对 | 锚点太多或缺命门特征 | 减到 1 到 2 个锚点，补 3 到 5 个命门 |
| 文字错 | 没加引号，字太多，质量档低 | 加引号，减字数，提高质量档 |
| 人物换脸 | 身份锁不够靠前，参考图职责不清 | 身份锁放第一段，删外观罗列 |
| 漏指令 | 指令冲突，关键要求埋在中间 | 关键要求前置，删冲突项 |

一次只改一个变量。同样的错误换了写法仍然出现，属于这个模型的上限，换模型或拆成多步，不继续重试。

## 8. 提交前自检

- 主焦点只有一个。
- 风格锚点不超过 2 个，主色不超过 4 种。
- 画面文字是用户原文并加了引号。
- 没有互相冲突的指令。
- 没有 masterpiece、8K、超高清这类空词。
- 没有添加用户没提到的角色、物体、品牌和文字。
