# 角色动作镜头

来源等级的含义见 prompt-method。本节多为通行做法，未在本产品实测。写具体提示词时同时读目标模型的写法（model-seedance 或 model-video-general）。

## 默认
- 一条视频只做一个主要动作，时长取 list_models 里最短的一档（通常 5 秒左右）。动作多就拆成多条。
- 单镜头，机位固定或只做一种简单运动。
- 有角色图时把它作为首帧或角色参考。两种用法的区别：
  - 作首帧：画面从这张图开始，构图和背景都继承。适合让立绘原地动起来。
  - 作角色参考：只取身份和服装，构图和场景另写。适合把角色放进新场景。

## 必写 [通用]
1. 角色只有一个，画面里没有其他人。
2. 动作的起止：从什么姿态开始，到什么姿态结束。复杂动作从「已经在进行中」写起。
3. 动作的重量：重武器会拖慢身体，落地要屈膝缓冲，披风和头发晚半拍摆动。
4. 机位：全身入画还是半身，镜头动不动。
5. 背景：沿用首帧，或纯色（方便抠像），或写明场景。
6. 身份和服装全程一致。

## 骨架
```
[恰好 1 个角色；参考素材的用途] + [起始姿态与位置] + [动作：起、过程、止，按秒分拍] + [重量与跟随：武器、披风、头发] + [机位：固定或一种运动] + [背景] + [约束：身份与服装全程一致，无配乐，无字幕]
```
具体段落的写法按目标模型的技能来。

## 常见动作
- **待机**：呼吸起伏，重心在两脚间轻微转移，头发和衣摆被风带动，眨眼。写「原地，不移动位置」。
- **行走、奔跑**：写方向（向画面右），步幅和节奏，地面线保持水平。
- **攻击**：蓄力、出手、收势三拍，每拍一句。写武器的轨迹和身体的跟随。
- **施法**：手势、光效从哪里出现、照亮了哪里、结束时光效消散。
- **转身展示**：角色原地缓慢转一圈，或镜头环绕一圈，二选一；写「服装细节始终可见」。
- **登场**：从画外进入或从暗处走到光里，最后停在一个定格姿态。

## 循环动画
用户要可以循环播放的动画（待机循环、行走循环）时：
- 模型支持首尾帧时，首帧和尾帧用同一张图。
- 提示词写「动作在结尾回到起始姿态」。
- 在汇报里说明：首尾是否真正接得上要人工检查，通常需要后期裁剪。

## 反默认
- 不要镜头乱动：写清楚「机位固定」或唯一的一种运动。
- 不要中途换装、变脸、多出手指：写「身份、服装、武器全程一致」。
- 不要自带配乐和字幕。
- 不要让角色走出画面，除非这就是要求。

## 出片后看什么
视频结果会附一张带时间码的联系表：
- 动作是否完成，起止姿态是否符合要求。
- 各帧里角色的脸、服装、武器是否一致。
- 有没有多出来的人或物。
- 时长是否符合参数。
