# Seedream / 即梦写法

适用：模型名含 `seedream` 或 `seededit`。核对日期 2026-10；来源等级的含义见 prompt-method。

## 写法
- 中文直写，不需要翻译。[社区]
- 主体加动作加环境，简洁优于堆形容词；写明用途。[官方]
- 一句里只放一个风格。[社区]
- 版式写分区坐标（左三分之一是主体，右侧三分之二是文字，右下角是按钮），比泛泛描述更听话。[社区]
- 画面文字用双引号写死。[官方]
- 负面约束写成句子放在末尾。不支持 `(词:1.3)` 这类权重写法。[社区]

## 改图与多图
- 用「图一、图二」指代，并逐张说明要做的操作。[官方]
- 多参考图控制身份与一致性，比纯文字描述稳。[社区]
- 可以在参考图上画箭头或方框标出要改的位置。[官方]

## 组图
- 一次输出多张关联图：写「一系列」「一套」「组图」，或写明确的数量。适合系列图、分镜、套图。[官方]
- 张数上限以 list_models 返回的为准。

## 已知问题
- 提示词里不写色值（#0E0D0C）和占比（约 60%），色板只用颜色词描述。写了会被当成文字画进画面。[实测]
- 版本差异：较新的版本指令遵循和版式更强，较早的版本写实质感可能更好。[社区，待复核]
