# Seedance 范例

需求：10 秒，16:9。图1 是老修表匠，图2 是他的店。他修好一块旧表，学徒推门进来，他只说一句「放那吧」。

```
场景概述：恰好 2 个角色，不重复：修表匠、学徒。写实电影质感。小镇钟表店，傍晚。修表匠刚修好一块旧怀表，学徒推门送来新的活。一镜到底，10 秒。
参考素材：
图1 用作修表匠的角色参考：脸、发型、服装按原图，包括左眼的放大镜片；不继承背景和姿势。
图2 用作场景参考：只取店内空间、木柜和玻璃柜台的材质；不作为首帧，不继承构图、角度和调色。
空间地图：工作台在画面中央，台灯在工作台左端；店门在画面右后方，离工作台约 4 米；墙上的挂钟群在画面左后方。机位在工作台正前方，全片不越过工作台与店门的连线。
首帧站位：修表匠坐在工作台后，身体朝画面左，低头看手里的怀表；店门关着，学徒在画面外。
镜头：约 40mm，胸口高度，离工作台 2 米；景深覆盖工作台和店门；轻微手持，只在修表匠抬头时微调构图，不推、不变焦、不甩。
动作时间轴：
0-3 秒：修表匠用镊子把最后一枚齿轮按进机芯。秒针开始走动。他停住呼吸看了一秒。
3-6 秒：店门被推开，学徒抱着一个纸盒进来，停在门口一米处。修表匠的眼睛先抬起来，头随后转过去。
6-10 秒：修表匠把怀表轻轻扣上，放到台灯下，下巴朝工作台右侧的空位点了一下。最后一帧停在怀表在灯下反光。
物理：纸盒有分量，学徒的手臂微微下沉；怀表盖扣上时有轻微回弹。
光线：台灯是唯一主光，从画面左侧照亮修表匠的手和怀表；店门方向暗两档，门外是冷蓝的傍晚天光。
声音：只要现场音效，不要音乐，不要字幕。挂钟群的滴答声，门铃一声，纸盒摩擦声。修表匠的声音低沉沙哑，语速慢。台词只有：「放那吧。」学徒不说话。
角色表演：修表匠：状态是专注后的松弛；想要再多看一眼修好的表；身体节奏慢而稳，手比头先动；变化点是学徒进门时把情绪收回到平淡的脸。
风格：写实电影剧照质感，自然动机光，暖黄台灯与冷蓝门外天光对比，细微胶片颗粒，自然的运动模糊。
约束：画面里恰好两个人，没有其他人；恰好一块怀表、一盏台灯；机位始终在工作台正前方；修表匠服装全片一致；无音乐，无字幕。
```
