# Seedance 视频写法

适用：模型名含 `seedance`。底稿：video-prompt 技能（2026-10 版）。来源等级的含义见 prompt-method。

时长、分辨率、画幅、素材数量上限以 list_models 返回的为准，走生成参数。

## 原则
- 整条提示词可以很长，单个节拍不能塞满：时间轴里每个节拍最多 3 句。
- 没写到的东西模型会自己编。人数、道具数量、站位、光向、谁说话，重要的都写出来。
- 开头定调：人数、媒介、发生什么、每份参考的用途放在最前面。
- 只写画面里有什么。否定式常被忽略或反向执行，改成肯定式（「不要向后摔」写成「向前扑倒」）；禁令集中放在最后一段。
- 写行为和物理，不写情绪词。写下颌、呼吸、眨眼、视线、手上的动作。

## 骨架
每段用标签开头，按顺序写。与本条无关的段省略。

```
场景概述：恰好 N 个角色，不重复：[谁]。[风格媒介一句]。[地点、时间]。[发生什么]。[一镜到底 / 硬切 N 镜]，[时长] 秒。
参考素材：
图1 用作角色参考：[保留什么：脸、发型、服装、配饰]；不继承背景、姿势、构图。
图2 用作场景参考：只取空间和材质；不作为首帧，不继承构图、角度和调色。
空间地图：[地标物及位置，用画面左 / 画面右 / 画面中央和米数]；机位在[哪一侧]，全片不越过[哪条线]。
首帧站位：[第一帧谁在哪、朝向哪、看向哪]。
镜头：[焦段]，[机位高度与距离]；[运动方式]，[不做的运动]。
动作时间轴：
0-3 秒：[可见动作]。[可见动作]。[结束状态]。
3-6 秒：……
物理：[有重量的东西怎么动：惯性、接触、落地、液体、布料]。
光线：[单一光源逻辑：光从哪来、照到哪、哪里暗]。
声音：只要现场音效，不要音乐，不要字幕。[环境声]。台词只有：「[原文]」。其他人不说话。
角色表演：[角色]：状态……；想要……；身体节奏……；变化点……。
风格：[具体的媒介、光影、色彩、镜头质感]。
约束：画面里恰好 [N 个人 / N 件道具]，没有其他人。[身份和服装全片一致]。无音乐，无字幕。
```

一个完整范例见 `references/example.md`。

## 各段要点

**参考素材**
- 参考素材按传入顺序编号，每一份都写用途、保留什么、不继承什么。不写用途时模型自己判断，常见错误是照抄构图而丢了脸。
- 图里已有的外观不用文字重写，保留项写类别名（脸、发型、服装）。重写的细节和图对不上时，模型要在两者之间取舍。
- 场景参考必须写「不作为首帧，不继承构图、角度和调色」。
- 首帧、尾帧素材是画面本身，不属于参考：首帧图里已有的内容不再描述，只写从这一帧开始发生什么。

**空间地图与站位**
- 方位只用画面视角（画面左、画面右）。模型不理解「主角的左边」。
- 位置用地标加米数（在灯旁，离门 3 米）。
- 每次切镜后重新写谁在哪、看向哪，模型不记得上一镜。

**动作时间轴**
- 按秒写节拍，秒段首尾相接，总和等于时长。现在时，短句。
- 复杂动作不要在中段才起步：直接从「已经在挥击中」开始。
- 关键动作写三件事：做什么、为什么、想要什么效果。
- 事件按因果顺序写，先触发再反应。
- 时间码只会被大致执行，要卡准剪辑点靠后期。

**物理与光线**
- 写重量和接触：重的东西拖慢身体，落地要屈膝缓冲。
- 巨型角色每条都写尺寸对比，并在画面里放一个参照物。
- 一个光源逻辑、一个阴影方向。

**声音**
- 只要现场音效，不要音乐。音乐属于后期。
- 台词只写在声音段，按每秒 3 到 5 个字预算。写「没有台词的人完全沉默」，否则模型会自己加语气词和笑声。

**表演**
- 给角色一个目标和一个阻碍，让争取的方式在镜头里变化。
- 写肌肉不写形容词：下颌咬紧又松开，鼻腔轻呼气。
- 静态镜头每 1 到 2 秒安排一个微小动作，否则画面会冻住。

**约束**
- 数量写死。最后一帧停在哪写清；要干净收尾写「硬切黑」，不写「淡出」。
- 画面里要出现的文字和 logo 留到后期，不交给模型。
- 不写年龄，用身份、服装、动作代替。写到未成年会让内容过滤明显变严。

## 用词替换
| 原词 | 换成 |
|---|---|
| 黑暗、dark | 低调光 |
| 猛地一震 | 快速动作 |
| 年龄数字、少年、小孩 | 身份加服装加动作 |

## 参数建议
- 分辨率优先选 720p：对提示词的响应最好，也更快更便宜；清晰度靠后期放大。[社区]
- 含可辨识写实真人脸的参考图可能被平台拦截，这类需求改用非写实画风或纯文字描述。[官方]
- 参考图 1 到 5 张效果最好。要多视角就传多张不同视图的图，不要一张多视角拼图。[官方]

## 提交前自检
1. 第一句写了确定的人数。
2. 每份参考都写了用途、保留、不继承，且对应用户真给的素材。
3. 秒段首尾相接，总和等于时长；每个节拍不超过 3 句。
4. 动作全是肯定式，按因果顺序。
5. 台词只在声音段，字数在预算内。
6. 没有写年龄，没有要模型生成的画面文字。
