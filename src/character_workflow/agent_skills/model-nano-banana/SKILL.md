# Nano Banana / Gemini 图像写法

适用：模型名含 `nano-banana`，或 Gemini 的图像模型。核对日期 2026-10；来源等级的含义见 prompt-method。

## 写法
- 用自然语言的完整句子描述场景，不堆关键词。[官方]
- 给上下文：这张图做什么用、给谁看。模型会据此推断景深、灯光、摆放这些专业决定。[官方]
- 写清主体、构图、动作、地点、风格。先确立主角和风格，再写细节。[官方]
- 中文、英文都可以。分栏结构（创意、细节、相机、风格、颜色）可控性好。[社区]
- 否定要求改写成正面描述，例如「背景干净无人」写成「空旷的纯色背景」。[官方]
- 比例融合稳定，可以写「七成 A 加三成 B」。[社区]
- 对相机词和微细节词敏感（尘埃、指纹、细划痕、颗粒），写了就会出现，不需要的不要写。[社区]

## 改图与多图
- 图已经对了八成时，直接提具体修改，不重新生成。[社区]
- 身份锁写「保持人物面部特征与图1 完全相同」，再写表情或动作的变化。[社区]
- 参考图数量上限以 list_models 返回的为准。参考多于 5 到 6 张时保真度下降，优先减少数量。[社区]
- 多图输入时，输出比例跟随最后一张图；需要别的比例要用参数指定。[官方]
- 风格转换要点名目标画风（例如直接写吉卜力），只把画风拆成「水彩背景、平涂两层」这类特征而不点名，会滑向普通水彩插画，主体的还原度也下降。[实测，待复核]

## 擅长
- 2D 与 3D 互转，草图或线框图转成品，按网格图生成像素画和精灵图。[社区]
- 复杂版式、带标注的剖面图和讲解图。[社区]
- 画面文字较强；轻量型号（Flash 一类）少用于复杂排版、长文字和多参考。[社区]

## 已知问题
- 多轮修改后角色会漂移。漂移明显时回到最初的参考图重新描述，不在漂移后的图上继续改。[官方]
