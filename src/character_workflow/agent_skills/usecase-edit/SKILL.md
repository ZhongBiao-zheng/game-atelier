# 改图与风格转换

来源等级的含义见 prompt-method。先确认所选模型支持以图改图（list_models 里有说明）；不支持的换模型。

## 必写
1. 每张输入图的职责（图1 是要改的图，图2 是风格参考）。
2. 改动清单：只改什么。
3. 保留清单：人物、姿势、服装、光线方向、构图、画幅中，哪些保持不变。
4. 输出画幅：默认跟原图一致。

每一轮修改都重写保留清单。不写的部分会漂移。

## 常见任务
- **局部修改**：写明区域和幅度（「把披风换成深红色，其余不变」）。改几何时写解锁的区域和幅度。
- **换背景、合成**：主体不变；写新背景，并要求光线方向、色温、透视、接触阴影与主体匹配。
- **换装**：图1 是角色，图2 是服装；保持面料纹理、颜色和图案；写自然垂坠与褶皱。
- **扩图**：写目标比例；延伸哪一侧的场景；补全被裁掉的物体；中心原图不变。
- **去除**：写去掉什么，用周围合理的纹理填充，颗粒、景深、光线与原图一致。
- **高清修复**：保持构图与身份，增加真实纹理；写「不要过度锐化，不要塑料皮肤」。
- **翻译图中文字**：保持原表面的质感，数字和符号不变，译文用用户给的原文。

## 风格转换
- 把目标风格拆成 6 项，逐项写「保持」或「改为」：媒介、线条、色彩、光影、纹理、构图。人物关系、站位、视线通常保持。
- 目标是知名画风时直接点名（例如吉卜力），再跟上命门特征。只拆特征不点名，会滑向相近的普通画风，主体的还原度也会下降。[实测，待复核]
- 主体要保持时写「图1 的主体保持原样」。

## 修改的节奏
- 已经对了八成的图，在它上面改剩下的两成，不整张重出。
- 一次只改一处。同时改多处时，出了问题无法判断是哪一处造成的。
- 一张图整张过模型的次数尽量不超过两次，次数多了质感下降、脸会变对称。需要多处修改时，在汇报里建议用户分区域处理。[社区，待复核]

## 出图后看什么
- 改动清单里的每一项是否改了。
- 保留清单里的每一项是否没变，重点看脸、手、文字。
- 画幅是否与原图一致。
