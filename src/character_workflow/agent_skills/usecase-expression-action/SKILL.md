# 表情表与动作表

来源等级的含义见 prompt-method。

## 默认
- 画幅：表情表 1:1 或 16:9；动作表 16:9。
- 网格排布，纯色背景，每格一个表情或动作。
- 张数：这是一张图里画多格，生成张数仍然是 1，除非用户要多张备选。

## 必写
1. 一致性锁写在格子列表之前：同一角色、同一服装、同一画风、同一比例。
2. 网格写死：几行几列，总格数，是否编号。例如「4 乘 4 网格，编号 1 到 16，每格结构一致」。
3. 逐格列出内容：编号加表情或动作。
4. 「不新增角色，不添加文字」（需要标注时写出标注原文）。
5. 格子之间用细线分隔还是无分隔，二选一写清。

## 表情
- 写肌肉和部件的变化，不只写情绪词：眉毛压低、嘴角向下、眼睛睁大露出上眼白。
- 换嘴形时写「原来的嘴线被整体替换成新嘴形，一张脸只有一个嘴」。张嘴写成「整块实心深色嘴形，外圈无描边」，并把「开口旁残留微笑线」写进避免项。只写「嘴张大」时，模型会保留默认嘴线再叠一个开口。[实测]
- 这个问题有随机性，表情表至少出 2 张挑。[实测]

## 动作
- 每格写一个动作的一个瞬间，写重心和四肢位置（左腿在前屈膝，右手后摆）。
- 连续动作（走、跑、攻击）按顺序编号，并写「同一视角，同一地面线」。
- 给游戏用的序列帧只能当草稿：帧间一致性不足以直接使用，在汇报里说明。

## 骨架
```
[用途：角色表情表 / 动作表，画幅，纯色背景] + [一致性锁] + [网格与编号] + [逐格内容] + [画风] + [约束：不新增角色，不添加文字]
```

## 出图后看什么
- 格数和排布是否与要求一致。
- 每格是否同一个角色。
- 放大看每个表情的嘴部有没有双线。
- 相邻格是否雷同。
