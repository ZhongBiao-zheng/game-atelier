# GPT Image 系列写法

适用：模型名含 `gpt-image` 的模型。核对日期 2026-10；来源等级的含义见 prompt-method。

## 写法
- 顺序：场景 → 主体 → 关键细节 → 约束。第一句写用途（宣传海报、UI、角色设定图），它决定完成度。[官方]
- 中文、英文都可以，跟随用户的语言。复杂需求用短标签分段或换行。[官方]
- 写实直接写「真实照片」。相机参数只影响整体观感，不会被精确模拟。[官方]
- 人物写尺度、身体取景、视线、与物体的交互，例如「全身可见，包括双脚」。[官方]
- 海报类第一句先声明主题与类型，例如「游戏美术宣传海报，角色 KV」。[实测]
- 负面约束写成句子放在末尾（不要……，避免……）。

## 画面文字
- 原文加引号；写字体、字号层级、颜色、位置；要求逐字渲染、只出现一次。[官方]
- 难拼的词逐字母拼出。小字和密集信息用较高的质量档。[官方]
- 长段正文仍会出错，只写死标题，正文用模拟文本块代替。[社区]

## 改图与多图
- 改图：写「只改 X」加「其余保持不变」；每轮重复保留清单。精细改动把饱和度、对比度、版面、文字、机位、周边物体都写进保留清单。[官方]
- 多图按图1、图2 编号并描述各自作用；写清图之间如何作用（把图2 的风格用于图1）。合成要写位置、光线、透视、比例、阴影匹配。[官方]
- 有主体参考图时文字越短越听话：删掉外观罗列和排除段，只写氛围、动作、构图。[实测]
- 先用原图拿准身份和结构，把成功的图当作新的锁定图，再加材质或风格参考做局部优化。[实测]
- 做角色板时不要把另一个角色的角色板当版式参考，版式用文字逐区描述。[实测]
- 透明背景：用透明背景参数，输出格式选 png 或 webp；提示词写「主体孤立在完全透明的背景上」。[官方]

## 尺寸
合法的尺寸、比例、质量档以 list_models 返回的为准。固定像素的官方规则：最长边小于 3840，两边为 16 的倍数，长短边比不超过 3:1。[官方]

## 已知问题
- 多轮编辑后细节漂移：关键细节每轮重新写出。[官方]
- 写 lush、detailed 会让动画画风出现零碎云朵和斑驳纹理，改写「单一焦点、大色块、云少而整」。[社区]
- 动物角色做成潮玩时默认把整张脸画满毛，要写「独立的 PVC 面壳，毛绒头套包围」。[实测]
- 表情特写会在新嘴形旁残留原来的微笑线：写「原嘴线被整体替换，一张脸只有一个嘴」，张嘴写成「整块实心深色嘴形，外圈无描边」。这个问题有随机性，至少出 2 张挑。[实测]
- 三视图里左右不对称的部件，背面要写明「角色转身 180 度，正面在画面右侧的 X，背面视图中位于画面左侧」。[实测]
- 写实人像只列五官名称时，多张图会趋同、笑容发假；五官要写得更具体，表情不要写死成同一个动作。[实测，待复核]
