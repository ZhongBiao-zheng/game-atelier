# 角色立绘

来源等级的含义见 prompt-method。项目规范或类别规范里写了画风、比例、配色的，以规范为准。

## 默认
- 画幅：单人立绘 2:3；卡面 3:4。
- 一张图一个角色，全身可见（含双脚），除非用户要半身或特写。
- 背景：纯色或大幅简化，方便后续抠图和合成。用户要带场景时再写场景。

## 必写
1. 身份与世界观：职业、阵营、时代（约唐代的游侠，近未来的机修工）。
2. 外观拆解：脸型、发型、服装的材质分区、配件、一个标志性元素。
3. 姿态与视线：姿态要体现性格，写重心落在哪条腿、手在做什么、看向哪里。
4. 画风：媒介与笔触（厚涂、赛璐璐平涂、半写实），线条性质，几头身。
5. 光：一个主光方向，加一条轮廓光把角色和背景分开。
6. 色板：主色加辅色加一个点缀色，不超过 4 种。

## 骨架
```
[用途：游戏角色立绘，画幅] + [身份与世界观] + [外观拆解] + [姿态、重心、视线] + [画风与比例] + [主光与轮廓光] + [色板] + [背景：纯色] + [约束]
```

## 反默认
- 不要正对镜头的直立站姿：写三分之二侧身或有重心偏移的姿态。
- 手容易出错：写手的具体动作和可见范围；持武器时写握持方式。
- 不堆装饰：标志性元素只留一个，其余简化。
- 画面里不加文字、签名、水印和边框。
- 四周留出裁切余量，头顶和脚下不贴边。

## 有参考图时
- 有角色参考图：文字越短越听话。删掉外观罗列，只写姿态、表情、氛围和构图。[实测]
- 有画风参考图：写「只取线条、配色、笔触和光影，不复制其中的人物、服装和构图」。
- 两者都有：分别声明职责，身份锁放在第一段。

## 出图后看什么
- 全身是否完整，手和武器是否正确。
- 服装与标志性元素是否和用户描述或参考图一致。
- 背景是否干净到可以抠图。
