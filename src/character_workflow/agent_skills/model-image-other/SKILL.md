# 其他图像模型写法

核对日期 2026-10；来源等级的含义见 prompt-method。没有专门条目的模型，按「通用」一节写。

## 通用
按 prompt-method 的顺序写完整句子：用途 → 主体置景 → 调性 → 镜头 → 光影 → 质感 → 约束。画面文字用引号写死。参考图按传入顺序称图1、图2，并逐张写用途。

## FLUX
- 主体、动作、风格、环境，靠前的词权重更大；长度 30 到 80 个英文词为宜，英文为主。[官方]
- 不支持负面提示。只描述想要的内容，「不要 X」改写成对应的正面描述。[官方]
- 颜色用 HEX 并绑定到具体物体，遵循度高，适合品牌色。[官方]
- 画面文字：引号、位置、字体。[官方]
- 支持结构化 JSON 提示词（场景、主体、风格、色板、光线、构图、相机）。[社区]
- 以改图为主的型号：一条明确的编辑指令；用描述指代主体，不用代词；写明保留项；避免 transform 这类会导致整体重画的动词。[社区]

## 中文模型
- Qwen-Image：中文长文字渲染强，适合中文海报、书法、信息图。[社区]
- 混元图像、可图：中文理解好，按通用写法。[社区]

## 文字与矢量
- Ideogram：文字排版与字标强，适合字标和文字海报。[社区]
- Recraft：矢量输出与品牌一致性，适合 Logo 和图标交付。[社区]

## Stable Diffusion 系
关键词写法：逗号分隔的短语；负面提示单独填在负面提示参数里；用到 LoRA 时写触发词。[社区]
