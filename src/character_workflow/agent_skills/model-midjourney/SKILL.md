# Midjourney / niji 写法

适用：模型名以 `mj-` 开头，或含 `midjourney`、`niji`。核对日期 2026-10；来源等级的含义见 prompt-method。本节条目多为社区来源，官方文档未核对到原文。

这类模型的写法和其他图像模型相反：其他模型读完整句子，它读英文短语。

## 写法
- 英文短语，逗号分隔，不写长句，不写版式说明。[社区]
- 顺序：主体 → 环境 → 风格 → 光线 → 机位。主体和最重要的风格词放最前。[社区]
- 风格锚点 1 到 2 个。[社区]
- 内容写全之后，再单独写一层整体调色和大气：低饱和统一色调、低反差、atmospheric haze，可以加摄影指导的名字作参考。缺这一层画面没有统一的影调。[实测，待复核]
- 不要在正文里写 "no X"，可能反而把 X 画出来；要排除的东西填进排除参数。[社区]
- niji 系用于动漫画风。

## 参数
画幅、风格化程度、多样性、排除项、参考图权重等都走生成参数，不写进提示词正文。可用的参数和取值以 list_models 与工具描述为准。参数的含义：
- 风格化：低值贴近字面，高值更艺术化。
- raw 模式：关闭默认美化，更贴提示词。
- 多样性：控制一组 4 张之间的差异。

## 参考图
- 风格参考只迁移色彩、质感、光线，不迁移内容。
- 角色或物体参考每次一张；风格化程度高时，要相应提高参考权重。
- 图片提示必须配文字，单独一张图无效。

## 限制
- 一次固定出 4 张。
- 文字渲染弱。画面里需要准确文字时换别的模型，或留出空位由用户后期排字。
- 不承担改图里「只改一处、其余不变」这类精确编辑。

## 从其他模型的写法转过来
删掉版式段和文字段，压成英文短语，风格锚点留 1 到 2 个，排除项移到参数。
