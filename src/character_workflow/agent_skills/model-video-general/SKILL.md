# 通用视频写法（Kling、Sora、Veo 等）

适用：模型名不含 `seedance` 的视频模型。底稿：video-prompt 技能（2026-10 版）。来源等级的含义见 prompt-method。

时长、分辨率、画幅、素材数量上限以 list_models 返回的为准，走生成参数，不写进正文。

## 骨架
- 没有参考图：`[总纲：风格、氛围、禁止项] → [场景与人物外形] → [分镜 A → B → C] → [声音与调色]`
- 有参考图或首帧图：`[时长与类型] → [逐张参考图的用途] → [逐秒时间轴] → [风格与约束]`

## 每条都过一遍的六个维度
| 维度 | 内容 |
|---|---|
| 镜头语言 | 角度、运镜、焦距 |
| 主体与行为 | 外形、动作序列 |
| 场景 | 地点、物理细节、氛围 |
| 光与质感 | 灯光冷暖、材质、色彩风格 |
| 情绪与约束 | 情绪基调、明确的禁止项 |
| 后期 | 调色、音乐、音效 |

## 写法
- 每个镜头只安排一个主要运镜。
- 运镜写成「中文（英文）」：轨道推镜（Dolly In）、环绕（Orbit）、跟随（Tracking Shot）、横移（Lateral）、上摇（Tilt Up）、闪摇（Whip Pan）、主体锁定（Camera Locked On Subject）。
- 动作按节拍写，短片段更听话。画面里的人不超过两个时更稳。
- 颜色设 1 到 2 组对比：场景主色对服装色。冷暖对冲强于同色系渐变。
- 否定要求尽量改写成正面描述。
- 写成一段可以直接使用的指令，不用表格和标题符号；可以用「0-2 秒：」这样的时间段标签。

## 图生视频（有首帧图）
首帧图里已有的外形和场景不再描述，只写主体和运动：谁在动、怎么动、镜头怎么动、结束在什么状态。[社区]

## 参考图绑定
- 参考图按传入顺序称图1、图2，每张指定唯一用途：画面基底、主体形态、目标形态、局部素材。
- 绑定只写身份（图1 是角色，图2 是场景），不描述图里的布局和颜色。
- 关键镜头里重复引用对应的图，每个转折写清「从哪张图到哪张图」。
- 界面、卡牌、商品类：写「保持布局、按钮位置、文字层级不变」，只加光效、粒子、镜头、弹出、翻转等动效。
- 结尾落在可以剪辑的画面上。时间轴总时长等于要求的时长。

## 各家差别
- **Kling / 可灵**：文生视频写主体、运动、场景，再加镜头、光线、氛围；图生视频只写主体和运动。[社区]
- **Veo**：运镜、主体、动作、环境、风格。对白用引号；音效和环境声单独写明；可以按时间戳分段。[官方]
- **Sora**：时长和尺寸放参数；动作按节拍写；对白单独成段；首帧参考图要和目标分辨率一致。[官方]

## 约束
- 画面里的文字和 logo 留到后期。
- 不写年龄，用身份、服装、动作代替。
- 需要音效而不要配乐时明确写出；模型是否生成声音看 list_models 里的参数。
