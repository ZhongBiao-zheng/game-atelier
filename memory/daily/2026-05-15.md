### v1.0 → v2.0 的核心变更

| 维度 | v1.0 | v2.0 |
|---|---|---|
| 路径 | B 阶段 (2-3天) → C 阶段 (2-3周) | **B+ 单阶段 (2 周)** |
| Web 角色 | B 只读、C 主交互 | 一上来就双向 |
| Web → Skill 通信 | C 阶段 inbox 队列 + "回 CC 输继续" | **剪贴板桥接 + Cmd+V Enter** |
| 总工期 | 3-4 周 | 2 周 |

### 三个被推翻的隐含前提

1. ❌ "画师不愿在 CC 打字" → 实际：画师本来就在跟 LLM 打字
2. ❌ "真痛点是 TUI 心智门槛高" → 实际：真痛点是"重复喂上下文"，Skill 直接解药
3. ⚠️ "C 阶段必须 Web 主交互为画师不愿打字买保险" → 部分修订：画师确实必须 GUI，但不需要 Skill 退到后端

### B+ 核心创新点：剪贴板桥接

- Web 写文件后浏览器 `navigator.clipboard.writeText('继续')` + toast 提示
- 画师 1.5 次按键操作（Cmd+V + Enter）触发下一轮
- 比 v1.0 C 阶段"切窗口 + 打字'继续'"轻一个数量级
- 没用 CC file watcher hook（CC 不提供）、没用 OpenClaw（违反"零账号"原则）

- ✅ 答出真痛点的具体形式（"重复喂上下文"）
