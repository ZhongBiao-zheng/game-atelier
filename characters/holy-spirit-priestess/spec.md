# 圣灵祭祀（女）

> id: `holy-spirit-priestess`
> 创建时间：2026-05-18

## 角色定位
- **职业**：见习圣职者 / 治愈系冒险者
- **性别**：女
- **气质**：温柔治愈、亲切活泼，宝可梦主角团成员感

## 已确定要点
- **风格档**：卡通插画（类宝可梦杉森建图鉴风）—— 清晰黑色轮廓线 + 水彩平涂 + 柔和边缘阴影，色彩明亮干净
- **镜头**：全身立绘 —— 头到脚 + 居中构图，手游卡面 / 立绘标配
- **配色基调**：圣光金白 —— 主体象牙白 / 浅金，金纹圣装饰，轻盈明亮
- **服装**：白金圣职轻便冒险装 —— 短款圆领白色法袍（及膝），袍边金线圣纹绣边；腰间浅金宽腰带配圣徽扣；背披白色短斗篷（宽帽垂落肩背，不遮脸）；袍内搭白色短靴
- **头部**：兜帽自然垂落至肩背，脸完全露出；发型柔软中长，银白或浅金色调；五官清秀温和，双眸圆润有神，嘴角自然微笑
- **法器**：小型金边圣典 —— 左手单手轻握，随意垂于身侧或贴靠胸口，金扣镶嵌
