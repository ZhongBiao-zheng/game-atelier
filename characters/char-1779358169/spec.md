# 火栗狐

> id: `char-1779358169`
> 创建时间：2026-05-21

## 角色定位
- **类型**：火属性精灵 / 初阶进化形态
- **原型**：幼年小狐狸（四足兽形，非人形化）
- **战斗定位**：远程 / 特攻系
- **气质**：顽皮灵巧、少年感，眼神机灵带一点狡黠，动作轻快爱跳跃

## 已确定要点
- **风格档**：宝可梦式官方图鉴风卡通插画，参考幻兽帕鲁与宝可梦的精灵设计语言;清晰黑色轮廓线,明亮平涂,柔和阴影。
- **镜头**：全身立绘,白底,竖向 1024x1536,3/4 侧身角度,头到脚完整可见。
- **属性与战斗感**：纯火属性远程特攻;**不加明火火苗**,靠红橙主色调和尾巴形态体现火属性,留出后续技能动作里再加明火的余量。
- **配色基调**：栗红色 + 暖橙 + 蓬松白 + 翠绿眼;栗红为主毛色,暖橙用于尾巴/腹部/额头小焰形毛束,蓬松白用于胸前毛领,翠绿仅用于眼瞳。
- **体型**：四足幼狐,头身比偏可爱大头,四肢短粗,胸前毛领蓬松外撑,大尾巴长度接近体长。
- **视觉锚点**：① 胸前一圈蓬松外撑的白色毛领（最强记忆点）;② 大尾巴带橙红双色环纹/旋纹,尾尖橙色;③ 额头一撮向上翘起的火焰形毛束;④ 翠绿眼瞳与红橙皮毛形成强对比。
- **表情**：眉眼坚定带笑意,嘴角微翘露出小巧獠牙,神态机灵不凶恶。
- **姿势**：四足站立,身体微微前倾,左前爪轻抬,像下一秒就要冲出去,尾巴上翘形成 S 形轮廓。
