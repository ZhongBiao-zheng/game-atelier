# 数据

## 写在哪里

| 数据 | 位置 | 归属 |
|---|---|---|
| 单个节点的数据 | 画布文档里节点的 `data.payload`（≤ 256 KiB） | 项目：随画布保存、撤销、复制、导出 |
| 插件产出的图片与文本 | 画布上的普通节点（`create_image` / `create_text`） | 项目：与插件无关的普通内容 |
| 项目级插件状态 | `canvases/<project>/plugins/<id>/state.json`（≤ 1 MiB） | 项目；已在项目包里，接口尚未开放 |
| 应用级启用状态 | `<data_root>/.config/plugins.json` | 本机 |
| 项目批准 | `canvases/<project>/plugin-grants.json` | 本机，不进项目包 |

## 插件节点

```json
{
  "id": "plugin-…", "type": "plugin", "title": "精灵表",
  "data": {
    "plugin_id": "sprite-sheet",
    "node_type": "sheet",
    "plugin_version": "0.1.0",
    "package_digest": "sha256:…",
    "data_schema_version": 1,
    "payload": { "...": "插件自己的数据" },
    "generation_draft": null
  }
}
```

- 读画布时只校验外壳（插件 id、类型、版本号、payload 大小），不校验 payload 的内容，也不看插件是否存在。
- payload 只在写入时校验：经界面写入时宿主拦下超大、超深、非 JSON、含无效字符的数据；服务端只强制 256 KiB 上限。
- 插件自己负责 payload 的格式：读到不认识的版本或坏数据时回落到默认值，**在用户改动之前不覆盖原数据**。`payload_schema_version` 变化时由插件界面兼容读取旧格式（尚无宿主侧的迁移机制）。

## 停用或缺失时

| 情况 | 节点显示 | 数据 |
|---|---|---|
| 插件未启用 | 「插件未启用」+ 去启用 | 原样保留 |
| 未安装（换了机器、旧版本） | 「未安装此插件」 | 原样保留 |
| 版本不兼容 | 不兼容原因 | 原样保留 |
| 本项目未批准 | 「本项目尚未允许此插件」+ 允许 | 原样保留 |
| 界面出错 | 「插件出错」+ 重试 | 原样保留 |

占位节点照常移动、复制、删除、导出，连线保留；画布照常打开和保存。插件未启用时不能给它的节点连新的素材。

## 项目包

项目包携带节点 payload 与 `plugins/<id>/state.json`，不携带插件代码，也不携带批准记录。导入到另一台机器后，节点显示占位，启用插件并重新批准即可恢复。

## 已隐藏的节点

节点隐藏只影响显示。已隐藏的图片连给插件节点后，插件能读到它的完整内容，与它作为生成参考时的规则一致。批准弹窗的「?」里写明了这一点。
