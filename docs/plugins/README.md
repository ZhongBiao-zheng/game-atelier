# Atelier 插件开发

插件是 Atelier 的可选功能包。基础功能保持精简，游戏美术、3D 这类功能做成插件，用户在「设置 / 扩展 / 插件」里启用后才生效。

当前只加载**随安装包发布的官方插件**。本文档描述的就是官方插件今天实际走的路径；将来开放其他发布者时沿用同一套结构，开放之前必须完成的事项见 [安全与隔离](security.md)。

## 插件能做什么

插件不新增导航入口，也没有独立页面。它的功能只出现在已有的界面里：

| 贡献点 | 用户看到的 | 由谁渲染 |
|---|---|---|
| 画布节点类型 | 「添加节点」菜单里多出的条目，画布上的插件节点 | 菜单项与节点外框由宿主按清单画；节点内容由插件界面画 |
| 图片工具栏动作 | 图片节点工具栏「更多」菜单里的条目 | 宿主按清单画按钮；点击后建节点、打开面板 |
| 服务端路由 | （无直接界面）插件界面调用的本机处理 | 插件的服务端模块 |
| Agent 工具 | 画布内置 Agent 可用的工具 | 插件的服务端模块 |

节点内容面和编辑面板是插件自己的界面，运行在隔离的沙箱里。

## 三层结构

```text
plugins/<id>/manifest.json  ── 宿主只读清单 ──►  菜单项、工具栏按钮、节点外框（宿主渲染，零插件代码）
plugins/<id>/ui/            ── 构建成单文件 ──►  节点内容面、编辑面板（sandbox iframe，经消息通道与宿主通信）
plugins/<id>/server/        ── 首次调用时加载 ─►  /api/plugins/<id>/routes/* 与 Agent 工具（只有随应用发布的插件可以带）
```
