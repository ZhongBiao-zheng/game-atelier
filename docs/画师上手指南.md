# 画师上手指南

## 一句话节奏

**90% 时间在浏览器；触发下一轮只需 Cmd+V + Enter。**

## 第一次启动

1. 终端跑 `make install` 等待装完
2. 终端跑 `uv run python skill/viewer_server/server.py start` 起 server
3. 浏览器打开 `http://localhost:5173/`
4. 填图片存储目录（例：`~/Pictures/character-assets`）
5. 在 CC 里输入 `/character-workflow 你的角色名`

## 日常工作循环

1. **Web 看图**：左栏选角色，中栏看缩略图，点缩略图看大图 + prompt
2. **Web 改 spec / prompt / 写反馈**
3. **Web 点保存**：浏览器顶部 toast 提示 "已保存，切到 CC 按 Cmd+V Enter"
4. **切到 CC**（Mac: Cmd+Tab）：粘贴 + 回车
5. Skill 接管 → 出图 → 推回 Web 图廊

## 重要约束

- **同一时间只开一个浏览器 tab**（多 tab 行为未定义）
- **浏览器推荐**：Chrome 或 Edge（最新版）；Safari 在 localhost 也可用，但 clipboard API 偶有差异
- **剪贴板失败时**：toast 内点"手动复制"按钮 → 切 CC 粘贴

## 常见疑问

**Q：我改完 spec 但 Skill 没反应？**
A：确认两件事：(1) Web 上看到了 toast "已保存"；(2) 切到 CC 后按了 Cmd+V + Enter。

**Q：CC 崩溃了怎么办？**
A：重启 CC 后重新 `uv run python skill/viewer_server/server.py start` —— server 会自动清理 stale PID。

**Q：怎么撤回上一轮改动？**
A：Git。`characters/` 在 Git 里，所有改动可回滚。出图 PNG 不进 Git。
