本版新增应用内更新：后台下载并校验新版，确认后等待任务结束再重启，启动失败自动恢复旧版。同时修正 Tuzi GPT 2.5 的五档质量参数：低、中、高、超高、最高。

下载对应平台的安装包，完整解压到可写目录，双击「启动」。无需安装 Git、uv、Python 或 Node；断网可启动，AI 生成需要网络及供应商密钥。

- Windows x64：双击 `启动.bat`。
- macOS Apple Silicon：当前安装包未签名或公证。首次双击 `启动.command` 被拦时，macOS 14 及更早版本右键 →「打开」；macOS 15 起到「系统设置 → 隐私与安全性」点「仍要打开」。放行后启动器会清除本包目录的下载隔离标记。
- Linux x64：运行 `./启动.command`。

macOS Apple Silicon 另有桌面安装器 `Atelier-<版本>-macos-arm64.dmg`：打开后把 Atelier 拖进「应用程序」，从启动台打开，不出现终端，也不需要另开浏览器。安装器未签名或公证，首次打开被拦时到「系统设置 → 隐私与安全性」点「仍要打开」并输入登录密码。关闭窗口后 Atelier 留在菜单栏，从菜单栏图标退出才会停止服务。首次打开会把运行环境解压到 `~/Library/Application Support/game-atelier/runtime`（约 400 MB，应用内更新后最多保留 3 个版本）；把 Atelier 移到废纸篓不会删除这个目录，不再使用时可以手动删除，用户数据目录不在其中。

Windows x64 另有桌面安装器 `Atelier-<版本>-windows-x64-setup.exe`：双击安装到当前用户（不需要管理员），从开始菜单打开，不出现命令行窗口，也不需要另开浏览器。安装器未签名：浏览器可能提示文件不常下载，在下载列表里选择保留；运行时出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。电脑没有 WebView2 时安装器会联网补装。Windows 11 开启了「智能应用控制」的电脑无法运行本安装器，也无法运行压缩包版，可在「Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置」查看，显示「评估」或「关」的不受影响，Windows 10 不受影响。窗口使用系统标题栏，没有菜单栏：设置在页面里（也可按 Ctrl+,），复制、粘贴、撤销等在输入框里照常可用，F5 重新载入页面。关闭窗口后 Atelier 留在任务栏通知区域，从通知区域图标退出才会停止服务，日志也从这个图标的菜单打开。运行环境解压在 `%LOCALAPPDATA%\game-atelier\runtime`；在「设置 → 应用」里卸载 Atelier 会一并删除这个目录，用户数据目录不在其中、不会被删除。用安装器覆盖安装时，运行环境会重置为安装器自带的版本：重装请下载最新的安装器，否则会先回到旧版本，再由应用内更新升回。

解压后目录为 `GameAtelier/`，根目录的启动器保持固定，Python 和应用文件放在 `versions/<版本>/`。请完整保留目录结构，不要单独移动启动器或修改 `current`、`last-good` 文件。

用户数据仍保存在 `~/game-atelier` 或首启选择的位置。5.129.0 及更早安装包需手动更换一次：停止服务，将新包解压到另一个可写目录，再从新版启动。不要覆盖旧目录，也不要删除用户数据目录。确认新版可用后，可以删除旧安装包目录。

如果旧布局已安装 Windows 常驻服务，先用旧版的常驻脚本执行 `uninstall`，再用新版执行 `install` 并在系统任务计划程序里重新保存凭据。新任务指向安装目录根下的固定入口，以后切换版本无需重装任务；移动整个安装目录仍需重装任务。

附带 `.sha256` 文件用于校验下载完整性。新安装包会后台准备新版，顶栏出现「更新」后可确认重启；有任务时先等待，启动失败会恢复旧版。设置页可查看原因并重新检查。源码版仍请重新运行一键启动器更新。
