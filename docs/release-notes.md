## Cobrush 5.144.0

- **改名 Cobrush。** 桌面版直接运行新安装包即可替换旧的 Atelier，作品、设置和运行环境都保留；Mac 上装好后可把「应用程序」里的旧 Atelier 移到废纸篓。Windows 上不要先卸载 Atelier，否则运行环境需要重新下载。
- **首启选择存放位置。** 第一次打开先选作品放在哪里，可以放到 C 盘以外的磁盘。
- **画布文本节点改版。** 选中后在下方面板读全文、改字；选中一段写一句要求即可只改这段，可撤销。连好文本或图片后提示词可以留空直接生成。
- **模型。** Tuzi 预置自带 Midjourney，支持 Niji 8；新增 Vidu Q4、Q3 视频模型；认不出类型的模型可以直接在行里选类型。
- **创作台默认 Agent。** 直接说想要什么；结果下方新增「用作参考」，多张时按缩略图选。桌面版图片支持右键复制、另存为。
- **修复。** Windows 下载的图片文件名不再带完整路径；没有价格的结果显示「未计价」，以前添加的 Tuzi 供应商在「控制台 → 供应商」编辑该供应商、展开「高级」把计费分组填为 default 即可显示花费。

## 下载与安装

下载对应平台的安装包，完整解压到可写目录，双击「启动」。无需安装 Git、uv、Python 或 Node；断网可启动，AI 生成需要网络及供应商密钥。

- Windows x64：双击 `启动.bat`。
- macOS Apple Silicon：当前安装包未签名或公证。首次双击 `启动.command` 被拦时，macOS 14 及更早版本右键 →「打开」；macOS 15 起到「系统设置 → 隐私与安全性」点「仍要打开」。放行后启动器会清除本包目录的下载隔离标记。
- Linux x64：运行 `./启动.command`。

macOS Apple Silicon 另有桌面安装器 `Cobrush-<版本>-macos-arm64.dmg`：打开后把 Cobrush 拖进「应用程序」，从启动台打开，不出现终端，也不需要另开浏览器。安装器未签名或公证，首次打开被拦时到「系统设置 → 隐私与安全性」点「仍要打开」并输入登录密码。关闭窗口后 Cobrush 留在菜单栏，从菜单栏图标退出才会停止服务。首次打开需要联网下载约 130 MB 的运行环境，解压到 `~/Library/Application Support/game-atelier/runtime`（约 400 MB，应用内更新后最多保留 3 个版本）；网络不好时可在本页下载 `GameAtelier-<版本>-macos-arm64.tar.gz`，在首次打开的界面点「从文件导入」；把 Cobrush 移到废纸篓不会删除这个目录，不再使用时可以手动删除，用户数据目录不在其中。拖入新版覆盖后，已有的运行环境照常使用，由应用内更新升级；不会被换回旧版。桌面应用原名 Atelier：装好 Cobrush 后，「应用程序」里的旧 Atelier 可以移到废纸篓，作品、设置与运行环境都保留。

Windows x64 另有桌面安装器 `Cobrush-<版本>-windows-x64-setup.exe`：双击后点「立即安装」，装到当前用户（不需要管理员，可点「更改」换位置），装完点「开始使用」，首次打开时联网下载约 145 MB 的运行环境（网络不好时可在本页下载 `GameAtelier-<版本>-windows-x64.zip`，在该界面点「从文件导入」）；之后从开始菜单打开，不出现命令行窗口，也不需要另开浏览器。安装器未签名：浏览器可能提示文件不常下载，在下载列表里选择保留；运行时出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。电脑没有 WebView2 时，安装器会先询问并联网补装（只有安装界面需要它）。Windows 11 开启了「智能应用控制」的电脑无法运行本安装器，也无法运行压缩包版，可在「Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置」查看，显示「评估」或「关」的不受影响，Windows 10 不受影响。关闭窗口后 Cobrush 留在任务栏通知区域，从通知区域图标退出才会停止服务。运行环境解压在 `%LOCALAPPDATA%\game-atelier\runtime`；在「设置 → 应用」里卸载 Cobrush 会一并删除这个目录，用户数据目录不在其中、不会被删除。用新版安装器覆盖安装会保留作品、设置与已有的运行环境；已通过应用内更新升到更新版本的，运行环境不会被换回旧版。已安装旧名 Atelier 的电脑直接运行新安装器即可：它会退出并替换 Atelier，开始菜单与「设置 → 应用」里只留下 Cobrush；不要先卸载 Atelier，那样会删掉运行环境，需要重新下载。

解压后目录为 `GameAtelier/`，根目录的启动器保持固定，Python 和应用文件放在 `versions/<版本>/`。请完整保留目录结构，不要单独移动启动器或修改 `current`、`last-good` 文件。

用户数据仍保存在 `~/game-atelier` 或首启选择的位置。5.129.0 及更早安装包需手动更换一次：停止服务，将新包解压到另一个可写目录，再从新版启动。不要覆盖旧目录，也不要删除用户数据目录。确认新版可用后，可以删除旧安装包目录。

如果旧布局已安装 Windows 常驻服务，先用旧版的常驻脚本执行 `uninstall`，再用新版执行 `install` 并在系统任务计划程序里重新保存凭据。新任务指向安装目录根下的固定入口，以后切换版本无需重装任务；移动整个安装目录仍需重装任务。

附带 `.sha256` 文件用于校验下载完整性。新安装包会后台准备新版，顶栏出现「更新」后可确认重启；有任务时先等待，启动失败会恢复旧版。设置页可查看原因并重新检查。源码版仍请重新运行一键启动器更新。
