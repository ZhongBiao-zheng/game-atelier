下载对应平台的安装包，完整解压到可写目录，双击「启动」。无需安装 Git、uv、Python 或 Node；断网可启动，AI 生成需要网络及供应商密钥。

- Windows x64：双击 `启动.bat`。
- macOS Apple Silicon：当前安装包未签名或公证。首次双击 `启动.command` 被拦时，macOS 14 及更早版本右键 →「打开」；macOS 15 起到「系统设置 → 隐私与安全性」点「仍要打开」。放行后启动器会清除本包目录的下载隔离标记。
- Linux x64：运行 `./启动.command`。

解压后目录为 `GameAtelier/`，根目录的启动器保持固定，Python 和应用文件放在 `versions/<版本>/`。请完整保留目录结构，不要单独移动启动器或修改 `current`、`last-good` 文件。

用户数据仍保存在 `~/game-atelier` 或首启选择的位置。旧布局安装包（5.128.0 及更早）需手动更换一次：停止服务，将新包解压到另一个可写目录，再从新版启动。不要覆盖旧目录，也不要删除用户数据目录。确认新版可用后，可以删除旧安装包目录。

如果旧布局已安装 Windows 常驻服务，先用旧版的常驻脚本执行 `uninstall`，再用新版执行 `install` 并在系统任务计划程序里重新保存凭据。新任务指向安装目录根下的固定入口，以后切换版本无需重装任务；移动整个安装目录仍需重装任务。

附带 `.sha256` 文件用于校验下载完整性。本次先提供新安装布局；应用内下载与切换功能尚未开放，更新仍需手动下载安装包。
