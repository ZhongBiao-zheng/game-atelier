功能说明书 V1 · 2026-05-14

嵌进日常工作的
角色出图协作工具

画师在一个聊天窗口里，把一个角色从"口头描述"推到"可用立绘"。 不切换工具，不写提示词，不重复已沉淀的修改意见。

核心 01
角色档案
结构化 Markdown，沉淀一个角色"画成什么样"
核心 02
AI 出图
读档案、生成提示词、调 GPT Image 2 出图
核心 03
聊天迭代
说哪里要改，AI 改提示词确认后重出图，意见自动沉淀
V1 功能范围
能做什么
2.1
建角色档案

画师在聊天里描述新角色，可以一两句开头，也可以一次性塞一大段。

AI 把零散描述整理成结构化的 角色档案 Markdown 文件，存到项目内 characters/{character_id}.md。

档案生成后，AI 把原文在聊天里贴给画师看，画师可直接说"这里改一下"，反复迭代到确认。

2.2
修角色档案

在聊天里说"把发色换成银色 / 把武器从矛改成双刃刀"，AI 改对应字段，改动后的档案再贴一次给画师确认。

旧版档案由 Git 自动保留版本，随时可回滚。

2.3
单张角色立绘出图（核心流程）
1
画师说"给暗影战士出一张立绘"
2
AI 读角色档案，生成完整提示词
3
AI 把提示词原文贴给画师过目——此时不出图
4
画师有意见 → 直接说"把武器描述改成更朴素" → AI 改完再贴 → 画师确认
5
画师确认 → AI 调 GPT Image 2 出图
6
文件下载到画师本地图片目录，按命名规则存储（见§数据约定）
7
聊天里通知画师，可在浏览器看图面板查看（V1 B阶段起）
画师未确认提示词前，程序不出图
2.4
聊天式迭代

出图后画师说"头发太花 / 武器位置不对 / 整体偏黑了"，AI 把反馈翻译成提示词修订。

先贴改后的提示词给画师过目 → 确认 → 再出图。

每一轮都走"提示词预览 → 画师确认 → 出图"的环，不会跳过确认步骤。

2.5
修改意见沉淀到长期记忆

每次有效修改意见，AI 提炼成一句规律写入 memory/character-prefs.md。

下次出图时 AI 自动套用，画师不用重复同一条意见。

项目通用规律（"本项目所有女性角色不要露脐"）也沉淀进同一文件。

画师可随时说"忘掉关于发型的那条规则"来清理。

2.6
同一角色再次出图（复用）

"再给暗影战士出一张换个姿势的立绘"——AI 直接套用已沉淀的修改意见 + 既有档案。

画师不用从头交代上次说过的所有意见。

仍然走"提示词预览 → 画师确认 → 出图"的环。

2.7
参考图按需注入

画师可在角色档案里手填 0 张到 N 张参考图路径——一张都不给也行，给五张也行。

参考图注入到 GPT Image 2 的输入里，提示词预览时一并告知画师引用了哪些。

也可在聊天里临时说"这次出图参考一下 xxx.webp"，单次有效，不写进档案。

2.8
模型备用切换

默认走 GPT Image 2。

画师可在聊天里说"这次换 nano banana pro 试试"——临时切换，单次有效。

GPT Image 2 出现故障或配额耗尽时，AI 自动告知并询问是否切备用模型。

输入输出约定
文件 & 格式
角色档案文件
characters/{id}.md

格式：Markdown 纯文本（不是 JSON）。画师可自由删字段、加字段——这是给人读的文档，不是给程序解析的协议。

命名：snake_case 英文，如 shadow_spear_warrior.md

# 暗影之矛战士 / Shadow Spear Warrior

## 基本信息
- ID: shadow_spear_warrior
- 角色定位: 近战刺客
- 世界观: 暗黑奇幻 / 影族流亡者

## 外观
- 性别: 女
- 年龄段: 青年（24岁）
- 体型: 修长精瘦，长期战斗训练
- 肤色: 苍白冷调，左颧骨有一道淡疤
- 发型: 黑色长辫至腰，辫尾缀三颗银珠
- 眼睛: 紫色虹膜，微弱发光——影族血脉觉醒标志
- 服装: 深色皮甲 + 影丝兜帽
- 标志武器: 黑曜石长矛"夜噬"，矛身刻紫色符文

## 风格基线
- 美术风格: 半写实风格化
- 色调: 冷暗主调（炭黑/深紫），紫色点缀光效，绝不出现暖色高光
- 头身比: 7.5-8

## 参考图（0～N 张，按需填）
- design-system/references/shadow_aesthetic_01.png（整体氛围基线）
- design-system/references/leather_armor_dark_02.png（皮甲细节）

## 反向约束（不要出现的元素）
- 不要明亮欢快色调
- 不要露脐 / 性感化服装裁剪
- 不要卡通比例
- 不要面带笑容
- 不要暖色高光
提示词展示格式
正向 + 反向 · 中文优先

AI 在聊天里发正向提示词 + 反向提示词两段纯文本，画师可直接说"把武器那句换成 X"，AI 改完再贴。

聊天里展示样式 准备出图，请确认提示词：

正向：青年女性，24岁，纤瘦精瘦体型，苍白冷调肌肤，左颧骨淡疤，黑色长辫缀三颗银珠，紫色微光眼瞳，神情冷静不带笑意，深色皮甲配影丝兜帽，手持黑曜石长矛矛身刻紫色符文，炭黑深紫主调点缀紫色光效，半写实风格化，7.5头身比

反向：明亮欢快色调，露脐，性感化服装，卡通比例，面带笑容，暖色高光

参考图：shadow_aesthetic_01.png（氛围基线）、leather_armor_dark_02.png（皮甲细节）

确认出图？还是要改 prompt？
出图文件命名
本地存储 · 不进 Git

存到画师本地配置的图片目录，按角色分子目录。初次使用时设置页选/粘贴图片目录路径。

# 命名规范
<image_root>/<character_id>/<场景短语>_<时间戳>_<序号>.png

# 示例
.../shadow_spear_warrior/standing_20260515-1430_01.png
.../shadow_spear_warrior/standing_20260515-1430_02.png
.../shadow_spear_warrior/attack_20260516-0930_01.png
项目长期记忆文件
memory/character-prefs.md

进 Git，画师可读可改。AI 自动追加，画师也可在聊天里直接命令增删。

## 项目级规律（所有角色通用）
- 本项目所有女性角色不露脐
- 武器一律朴素，不要繁复雕花

## 角色级规律

### shadow_spear_warrior
- 头发不要画太花（2026-05-15，第2轮出图反馈）
- 皮甲色调要接近炭黑，不要中灰（第3轮反馈）
典型工作流
完整走一遍
A
新角色，第一张图
1
画师 → "我要做一个暗影族女战士，长发黑色，紫眼，用黑曜石长矛，整体冷暗调。"
2
AI 整理成角色档案 → 贴给画师看 → 画师改两处 → 确认
3
画师 → "出张正面立绘。"
4
AI 读档案、生成提示词 → 贴提示词给画师看 → 画师说"加一句动感姿势" → AI 改完再贴 → 画师确认 → 出图
5
文件存到 shadow_spear_warrior/standing_20260515-1430_01.png
6
画师审图，发现"头发太花、武器太短"
7
画师 → "头发不要那么花，武器矛身延长一倍。" → AI 改提示词 → 贴给画师 → 确认 → 出图（_02）
8
"暗影战士头发不要画太花"被 AI 自动写进 memory/character-prefs.md
9
画师满意 → 进入 PS 优化（不在本工具范围）
B
已有角色，新场景
1
画师 → "再给暗影战士出一张侧面立绘。"
2
AI 自动套档案 + 之前沉淀的偏好 → 提示词预览 → 画师确认 → 出图
3
画师不用重复"头发不要花"这类已沉淀的意见
产品形态
V1 先上，V2 后续
▶ V1 当期交付
终端对话 + 本地 Web 看图面板
画师在终端聊天窗口对话、确认提示词、给反馈（主交互）
出图完成后可打开浏览器图廊，看图、对比（观察窗，只读）

V1 边界
不做什么 / 不承诺什么
V1 不做（V2 路线）
✕
角色三视图（正 / 侧 / 背）批量出图
✕
角色美宣海报、分镜、Q 版头像、表情包
✕
跨多张图的视觉一致性自动保证——V1 由画师人工把关
✕
风格漂移自动检测与告警（画师对风格的眼力比 AI 强）
✕
跨项目的角色档案库检索与复用
防误解：V1 不会做的事
✕
AI 不会自动检测风格漂移、跨图比对一致性——靠画师人眼 + 档案复用 + 长期记忆沉淀
✕
AI 不会绕过角色档案直接出图——所有出图必须有对应的角色档案
✕
AI 不会强制画师走完整流程——这是工具，不是枷锁。画师随时可以绕过 AI 手动改文件
