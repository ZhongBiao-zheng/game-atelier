# 画布只保留可见输入实线

2026-09-09 用户确认：取消来源虚线，普通生成不自动引用节点自身；画布连线、参考面板与实际提交必须一致。本决策替代 ADR-0007 的双线可视模型，以及 ADR-0013 创建本地工具派生边的部分；保留不可变 Generation Snapshot / Content Version origin 作为历史真源。

当前画布只有可编辑 Input Connection，按连接顺序参与生成，@ 不过滤或重排；来源追溯不画线。基于已有内容创作须创建显式下游输入。新结果复制实际输入关系，失败重试使用原快照与精确版本，不用失败节点的当前状态重建。专用编辑的源图须明确呈现，不采用普通隐藏自身输入路径。

旧虚线不能直接变为输入，避免增加未经选择的素材。旧画布备份后清理来源边，保留用户实线、内容、图层绑定与全部历史；不维护双模式开关。历史 Snapshot 的旧来源枚举仍是不可变记录，不构成当前生成规则。
