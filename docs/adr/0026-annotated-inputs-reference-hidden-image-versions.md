# 带标注输入连接与隐藏合成版本

问题：标注需要留在原图节点上反复编辑，同时把模型看到的图片固定为合成图；额外创建标注节点会使画布重复堆放同一张图片。

决策：图片节点保存版本绑定的矢量标注。合成 PNG 是文档中的不可变隐藏内容版本，原图的当前版本不变。Input Connection 的 `annotated` 标记选择合成版本，生成快照固定该版本，不同时发送原图。显隐只影响画布显示。

后果：输入解析增加标注分支；普通及批量提交前补合成，失效或被清空的标注不能静默退回原图。结果回连继承标记，复制与项目包携带两份版本。派生版本写入不增加撤回步骤，用户标注动作仍由原有文档历史管理。
