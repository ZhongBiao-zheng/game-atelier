# 项目拥有资产，文件夹只做引用分组

game-atelier 是个人工作台,不是团队制作管理系统。每个游戏项目固定拥有一个资产库；用户创建的“夏日版本”“V2 组件设计”“08.22 对外宣传片”等项目文件夹只保存名称、顺序和资产引用,不承担负责人、截止日期、交付状态、审批或交付快照。同一资产可出现在多个文件夹中,删除文件夹或移除成员都不删除资产。

角色皮肤仍是拥有完整流程的角色变体,V1 / V2 是并存的轻量 UI 方案。历史可追溯性复用现有 Job 中已经记录的提示词、参数和参考路径,不再额外建设依赖图或交付冻结系统。
