# 团队库以文件夹为接口,同步交给团队自有工具

2026-09-20 用户确认:团队之间分享生成成果与素材,不引入团队服务、账号或云端,而是把一个本机目录挂载为团队库,由团队已有的 SVN / Git / Perforce / 网盘 / NAS 在成员机器之间同步。系统只读写目录,永不执行同步命令,也不托管任何数据。

理由:每家游戏团队已经有一套美术资产的同步方式,接进现有目录比让他们再运维一台服务容易得多;产品的差异化正是「团队的资产在团队自己手里」,一上云就和 Tapnow 类平台抢同一个位置。目录方案让系统对公司、仓库类型和网络环境都不敏感,是「复用给任意团队」的前提。

后果:分享提醒只反映同步到达本机的时刻,没有毫秒级即时性;「只有作者能改」只能在界面层用本机显示名判定,文件层不设防;团队库靠根目录清单文件获得身份,挂载路径因人而异。这些都被接受,因为它防的是误操作,不是恶意;要真正的即时与权限就需要这条 ADR 明确拒绝的团队服务。
