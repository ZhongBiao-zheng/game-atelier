# ADR-0010: 用户确认的局部批量执行

状态：Accepted

画师需要把一批素材逐项送入已有生成节点,或把固定输入重复执行多轮;同时不希望为文本、图片、视频、音频重做一套节点。新增批量素材节点保存有序项,复用一层分组作为显式执行范围。服务端冻结计划、逐项按输入依赖顺序调度,每一步仍提交普通 Canvas Job 给唯一 Job Runner;同项结果通过不可变 Version ID 绑定,而不是读取节点上随运行变化的当前版本。第一版串行、每步单产物、首次失败停止,重启不自动提交剩余步骤。选择局部调度而非另起工作流引擎,保留原有模型协议、计价和产物落盘路径。本文取代 ADR-0006 中“分组永不执行”的限制,但连线不自动运行、禁止循环/嵌套分组和 Skill 自主编排的约束不变。ADR-0009 的“批量结果属于一个 Job”仅指单步候选;本功能是多个独立 Job 的计划,不把多项生成伪装成一次请求。
