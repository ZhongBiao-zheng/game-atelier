# 局域网共享画布

2026-11-26 确认，同一内网中的团队可直接共享指定画布。画布所有权与文件仍归房主，复制内容时，接收方获得成片和参考媒体的独立副本。

主服务继续绑定回环地址。继 ADR-0025 的团队网关之后，允许第二个独立的局域网监听器用于画布协作。房主共享第一张画布时启动，停止最后一张时关闭。默认端口 5181，冲突时顺延至 5200。局域网应用只注册 `/collab/v1/` 下的协作接口。

访客通过本机 Atelier 访问房主。UDP 信标用于发现，清单由房主返回，也允许手动输入内网地址。代理只访问经验证的局域网或回环 IP，按接口构造请求，禁止重定向。浏览器本机会话与每张共享画布的凭据分别校验。清单可公开，读取文档和媒体需要加入项目，写入还须核对当前协作权限。房主修改口令或停止共享后，旧凭据失效。

协议 v1 适用于可信内网，HTTP 不提供传输加密。房主选择是否设置访问口令。媒体按项目内版本 ID 查找，代理不接受路径、任意 URL 或上游认证头。外发生成参数使用字段白名单，第三方私有服务配置与密钥保存在来源机器。

房主串行提交同一画布的节点操作。浏览器的选区和拖动预览只在连接期间有效。撤回通过房主保存的操作历史核对作者和后续修改。断线时停止写入，访客仍能保存已打开的文档。副本按原始版本的摘要标记尚缺的媒体，重连并取得读取权限后补齐。用户可以只加载缩略图。

第三方插件通过清单的节点贡献项声明可共享的标量字段路径。数组元素按同一组路径投影。没有声明、版本不匹配或插件不可识别时，跨机器复制保留只读占位。房主的原始载荷不变。访客启用官方分镜插件时，镜头与角色编辑经协作操作同步，绑定素材从当前房间读取。
