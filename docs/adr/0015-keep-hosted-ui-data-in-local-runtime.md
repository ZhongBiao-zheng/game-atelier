# 网站界面连接本机运行时，不接管项目存储

网站只分发界面，持久项目、Job、媒体与密钥仍由回环地址上的 viewer-server 和原 `data_root` 拥有。
用户已同意这条改造方向；具体连接交互与权限契约随 PR 评审，在实现验收前不视为已上线。
与改存浏览器数据库相比，这保留现有文件工作流，也避免站点缓存清理变成项目删除；代价是用户仍需
运行本机服务并批准网站连接，不能把它宣传为纯网页、零安装或跨设备访问方案。

网站须经绑定精确 Origin 的显式配对；本地管理、网站编辑和 Agent 工具分别授权。
原始密钥不发给网站或 MCP，媒体、事件和下载与 JSON API 同样受保护。
不增加公网监听、云中转或通配 CORS 来规避浏览器限制；本地页面与网站使用相同业务 API 和鉴权边界。

细节见[开发说明](../local-workspace.md)及[连接契约](../contracts/local-connection.md)。
