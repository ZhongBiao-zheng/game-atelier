# 用应用级版本化创作资产连接 Studio 与 Canvas

提示词和单张图片由应用级个人创作资产库拥有，Studio 与 Canvas 只保存明确使用的资产身份和不可变版本；Canvas Project 不再拥有可独立编辑的本地提示词或资产副本。这样同一资产能跨创作空间保持身份、版本、标签和归档状态，同时已插入内容与生成快照不会被新版本静默改写。用户一旦编辑已填入的提示词，该草稿立即解除资产关联；未登记内容跨空间时必须通过“保存并加入画布”显式创建资产和项目关系。

该决定取代 ADR-0010 中“Studio/Canvas 传递总是复制为目标项目独立版本”的部分；Canvas Project 包与 WebDAV 的不可变同步快照设计继续有效。
