# 图片编辑配置与生成结果分离

局部修改与扩图不再把临时蒙版与参数附着在原图或结果图上，而由独立编辑节点保存固定源版本、参考版本、可编辑笔迹与生成草稿。用户需要反复修改选区且保留每轮结果，因此保存配置与付费生成分离，每次运行冻结快照并另建结果节点；原图后续换版或删除不影响已保存配置。

节点间以素材实线表达原图 → 编辑节点 → 结果图，额外参考图只保存在编辑配置中，不额外拉线。编辑节点不是参考素材提供者，不参与普通输入解析。相较继续复用图片节点，这增加一种配置对象，但避免编辑器状态丢失、结果与草稿相互覆盖，以及在途任务误读后续修改。蒙版作为不可变内容版本保存，笔迹只用于恢复编辑；复制与项目包同时携带两者。
