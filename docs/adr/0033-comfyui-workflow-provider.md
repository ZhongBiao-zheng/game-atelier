# ComfyUI 工作流供应商

2026-11-02，按已确认的 ComfyUI 工作流共享方案实施，分批交付。

## 决策

- `comfyui` 供应商对应一台本机 ComfyUI。仅接受 HTTP(S) 的 `127.0.0.1` 或
  `localhost` 根地址；传输固定到 loopback，禁用环境代理和重定向，不保存密钥。
- 模型对应已导入的 API 工作流，ID 为 `comfyui-<唯一标识>`。原始图存放于
  `<data_root>/comfyui/workflows/<id>.json`，模型目录只存输入声明。
- 工作流模块是唯一写入者。在 `keys_lock` 内更新工作流文件和模型目录，各文件原子替换；
  目录写入异常时恢复原工作流。读工作流也持同一把锁，避免读到写入中间态。
- 导入、编辑和删除属于本机管理权限，网站、Canvas Agent 与网关成员不能提交原始图。
  后续成员请求只能提交声明中的值和经素材上传接口获得的参考图。
- 输入声明记录节点 ID、节点类型和字段。每次运行核对三者并拒绝连线字段，失配必须报错。
  值按声明校验类型、范围、选项、文本长度与必填项，额外字段一律拒绝。
- 在线导入的数值类型优先采用 ComfyUI `object_info` 的 INT/FLOAT 声明，
  不由 JSON 默认值是否带小数点决定；无元数据时才按值推断。种子保留专用类型。
  重新导入仍保留管理员已保存的输入声明；历史误判需在编辑表中改正或重新新建导入。
- 有 `in:` 标记时，标题为 `in:提示词` 或 `in:prompt`（英文名不区分大小写）的
  普通文本字段可映射为主提示词，不限制节点类名。优先字段 `text`、`prompt`，
  否则要求该节点只有一个字符串字段；枚举选项不转为提示词。最多自动选中一个。
  其他标题保持普通文本；没有任何 `in:` 标记时才沿用首个 CLIPTextEncode.text，
  并排除标题含负向、反向、负面或 negative 的节点。管理员仍可手动调整声明。
- 本期仅支持 SaveImage 图片输出，收费确定为 0，菜单显示「本机」，耗时沿用 Job 时间戳。
  张数表示独立任务数，随机种子各自生成，固定种子时只允许一个任务。
- 轮询 `/history/{prompt_id}` 和 `/queue`，排队阶段为 `queued:N`，下载为 `downloading`。
  仅下载 `type=output` 图片。每个 SaveImage 前缀改为 `atelier/<job_id>`。
- 超时或取消只删除本任务排队记录；只有确认本任务正在运行才发送携带 prompt_id 的中断。
  真实 Windows 验收需要确认安装版本对定向中断的支持，不承诺旧版本全局中断的并发安全。

## 交付边界

A 批提供主机本机工作流管理、执行、创作台与画布参数表单。
B 批提供网关目录快照、声明参数与素材传输、成员端排队，以及 Studio / Canvas 的工作流控件。实际渠道转换保留输入声明，工作流全部图片产物经网关保存，实际费用记零。
C 批提供本机与成员画布局部重绘：只开放恰好一个 image 和一个 mask 声明的工作流，
不开放扩图。原图与独立遮罩分别上传；遮罩 RGB 为白色重绘、alpha 为白色保护，
同时满足 LoadImage 的反向 alpha 与 LoadImageMask 的颜色通道语义。提示词与工作流参数
原样传递，产物合成保留选区外像素。排队删除后复查运行状态；阶段回调和下载期间取消
同样停止本任务，成员等待主机取消落定后结束，不再提交剩余张数。
协议依据：[ComfyUI 遮罩节点](https://github.com/Comfy-Org/ComfyUI/blob/master/nodes.py)、
[定向中断接口](https://github.com/Comfy-Org/ComfyUI/blob/master/server.py)。
实际 ComfyUI 的模型文件、自定义节点和出图质量在 Windows 主机另行验证。
