# 角色工作台是管理视图，不是第二层项目

角色工作台采用类似项目页的聚合管理体验，但角色仍是项目拥有的资产，不成为新的资产归属边界。立绘、美宣和三视图由角色自身拥有；同时涉及多个角色或不涉及角色的 UI、视频继续由项目拥有，只在存在明确关联时出现在对应角色工作台。这样既能按角色集中找作品，又不会让同一 UI 或视频因为多角色参与而产生重复所有权。

角色关联采用“真实引用自动建立、用户可以显式补充”的组合方式。自动关系减少整理成本，手动补充覆盖导入成品或历史数据缺少引用记录的情况；两者都只影响聚合读取，不复制或搬动原资产。

关联挂在生产对象而非单个媒体版本：UI 使用页面，视频使用企划。生产对象的新版本自动继承聚合关系，避免每次生成后重复整理；角色工作台首页只突出各类定稿和最近作品，全部历史留在分类详情中。
