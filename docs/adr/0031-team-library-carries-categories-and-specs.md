# 团队库携带类别与团队规范，Agent 两边同时检索

2026-10-28 用户确认：团队库从「只放素材」扩展为也承载团队对素材的认知，让画布 Agent 在新项目里直接用上团队已有的定稿参考和规范。

- 分享时团队资产可带一个类别（来源已定稿时预填）；采用沿用该类别，采用副本直接进入采用所在项目的参考库。这推翻了原规则「采用不会自动设定项目类别」。
- 团队库目录新增 `specs/`：一份团队整体规范与按类别的规范，格式与项目规范同构。项目规范与团队规范冲突时以项目规范为准：项目规范更具体，团队规范是底线。
- 画布 Agent 出图时同时检索项目参考库与本画布挂载的团队库；把团队资产放上画布就是采用。Agent 只读本画布挂载的库，挂载决定可见范围。
- 团队规范任何成员都能在规范抽屉里编辑，不设作者限制，并发修改交给团队自己的同步工具（与 ADR-0020 一致）。

后果：同一类别名在不同团队里含义可能不同，采用沿用类别时不做映射；`asset.json` 的 `category` 与 `specs/` 都是可选扩展，旧版本读方按「忽略未知字段」照常工作。
