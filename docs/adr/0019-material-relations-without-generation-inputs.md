# 素材实线不隐式成为生成参考

2026-09-09 用户确认：抠图、切图与展开图层保留实线素材关系，但下游只使用直接接入的处理后素材；同时移除生成面板的“原任务输入／本轮冻结输入”重复信息。本决策替代 ADR-0018 的“只有输入连线”约束，保留其禁止隐藏参考、不可变快照与精确版本重试规则。

当前输入使用 `role: input`，独立本地处理产物使用 `role: material`；两种关系均为实线，仅 input 参与生成解析、参考列表和批量依赖。素材关联不带输入槽，不自动向上追溯，也不替代 Content Version origin 中的真实处理来源。用户仍可主动把同一素材接为参考输入。

图层栈已有素材绑定是归属的唯一真源，直接派生只读实线，不再持久化另一份连线。删除素材节点解除绑定，独立素材来源线可解除而不改历史。生成面板只呈现当前可编辑内容，不增加解释卡片；历史与安全重试继续由现有记录承担。这比把所有实线都当输入多一个明确的领域角色，但避免上游原图混入、重复素材和图层归属漂移。
