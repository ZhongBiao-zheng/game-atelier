# 网关共享中转与直接使用

2026-11-04，按资产库二期确认方案实施。本决策取代 ADR-0034 的「只读、无原文件、无写接口、只有主机能分享」四点。ADR-0020「文件夹即接口」仍是默认团队同步方式。

- 所有持有效成员密钥的人均可分享自己的库。主机库直接读取挂载目录；成员库上传到主机 `gateway-shares/`，成员离线不影响浏览。
- 清单和文件分开提交：清单暂存，缺失文件按 SHA-256 流式上传，完整后原子切换。单文件最多 500 MiB、每库最多 10000 条；公开模型拒绝额外字段，不传路径、生成快照、模型、参数或参考素材。
- 写入归属由鉴权密钥决定，不接收客户端 key_id。分享标识被其他成员使用或被主机停止时统一 404；主机停止保留标识墓碑，旧发布不能复活。分享人重新开启产生新标识。
- `gateway_share_store.py` 是主机共享文件唯一写入者，与密钥撤销共用锁。原文件和效果图全库按摘要去重；替换、删除与撤销时在锁内回收无引用文件，暂存清单的引用也受到保护。
- `team_library.py` 是本机发布状态唯一写入者；发布器负责清单、缺失文件、提交。启动、开关、扫描结束和十分钟周期触发；停止请求先持久化，断网后重试。每库串行，同步中的新扫描会排入后续同步。
- 浏览方以条目身份读取登记的原文件；本机代理流式回传，不落盘。库列表、条目仍用显式白名单，缩略图重编码。已传输的字节无法撤回；停止/撤销后新请求不可继续获取。
- 团队面板「使用」直接进入 Studio 对应参考槽或画布，追加且按文件身份去重，不创建个人资产。「复刻」仍需采用并冻结快照，网关共享库不提供复刻。
- 主机可管理所有成员共享，查看库容量与去重后的实际总占用，并停止某个库。不增加 SSE 同步、单资产分享、主机配额或视频转码。
