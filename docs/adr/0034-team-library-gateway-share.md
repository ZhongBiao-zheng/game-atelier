# 团队库网关临时共享

2026-11-03，按已确认的资产库 D 批方案实施。

ADR-0020 的「文件夹即接口」仍是团队同步与采用的默认方式。对于同一网络、未共享文件夹的同事，新增网关只读浏览通道；不建立团队资产服务或远程副本。

- 分享粒度为已挂载团队库。共享开关持久化于 `.config/team-library-gateway-share.json`，由 `team_library.py` 在挂载锁内唯一写入，原子替换；卸载库同时停止共享。
- 复用现有网关端口与密钥。所有未撤销的成员密钥可浏览，不要求管理员角色；不新增端口。
- 网关只发布显式白名单字段：标题、作者、类型、标签、分类、提示词正文及效果图数量。生成资产的模型、冻结快照、参数、参考素材、本机路径均不发布。
- 图片与提示词效果图只发重编码的 WebP 缩略图，最长边不超过 1024；当前复用团队库的最大 512 档。无原图、视频、音频下载或播放接口，无采用、上传或修改接口。浏览器能够看到缩略图，无法禁止截屏或保存已经收到的缩略图。
- 普通文件内部使用 `raw_*` 身份，网关转换为稳定哈希 `ta_*` 标识；不改变文件夹团队库的身份，不允许用文件路径寻址。
- 共享状态在每个请求中重新核对，在生成或读取缓存后再核对一次。停止共享后后续请求统一 404，不透露库是否存在。关闭前已经传给浏览器的字节无法追回。
- 成员本机代理从已保存的 Atelier 渠道取凭据；3 秒连接/读取超时，禁止重定向，失败渠道标记不可达。只转发已校验的白名单数据，缩略图不落盘，浏览器缓存为 `private, max-age=60`。
- 成员界面仅有查看与复制提示词；视频、音频用占位卡。进入团队 Tab、每 30 秒及页面重新可见时刷新；库消失或请求失败立即移除列表和详情中的媒体，显示「已停止共享」。不依赖 SSE。

验证包含两个独立数据目录的真实回环网关、关闭后已有缓存的访问、密钥撤销、路径闸门大小写与符号链接、公开字段和 GET 路由白名单，以及两个独立浏览器会话的开关流程。
