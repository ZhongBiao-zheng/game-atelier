# ADR-0045 本机视频处理与编码器分发

采用默认关闭的宿主插件 video-tools（ADR-0039）。由本机画布会话发起，项目版本是唯一素材句柄。机器上同时只有一个视频编码操作，按提交顺序执行。
宿主事件循环运行异步子进程并读取时间进度。项目写锁用于登记和提交；编码时用户仍可编辑画布。计费 Job、网关和模型用量独立于这条执行路径。

以项目号和调用方请求号定位项目内持久记录。编码结果先落同文件系统临时目录，提交时重新读取最新画布，在项目锁内移动产物并原子替换 canvas.json。
文档写入是发布点，同一次写入包括普通视频节点、版本与 local_tool 来源。取消也用这把锁决定终态。重启时按操作号核对已发布版本，清理该操作拥有的临时文件，未发布的任务标记中断。
项目导出的内容版本携带来源，运行状态保存在项目私有 .runtime 下。

macOS arm64 和 Windows x64 从 FFmpeg 8.1.3 官方源码构建独立 CLI，下载源码、签名和公钥均校验固定 SHA-256，再验证分离签名。采用 LGPL-2.1-or-later 配置和系统 H.264 编码器。
Windows 启用 NASM 汇编。版本化运行包随附 ffmpeg、ffprobe、对应源码、许可证、构建脚本、配置、第三方声明与文件清单。安装器记录整包摘要，使用时再核对两个程序的摘要并试编码、解码。
开发检出可用 ATELIER_VIDEO_ENCODER_DIR 指向含 SHA256SUMS 的同构建目录。源码安装缺少编码器时其余功能照常使用。Linux 本批提供明确的平台不可用状态。
