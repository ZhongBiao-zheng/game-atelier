# 用单内容创作资产连接 Studio 与 Canvas

提示词和单张图片由应用级个人创作资产库拥有，每个资产只维护一份当前内容。编辑会原位更新同一个
`asset_id`；产品不提供版本、归档、恢复或更新引用。详情页只有“使用”和“编辑”，编辑页统一维护标题、
标签与内容，并在底部提供经过二次确认的物理删除。

使用资产是一次明确的复制：Studio 把展开后的提示词复制进输入框，Canvas 把提示词或图片复制成自己的
Content Version。复制后不再保留可回写引用；生成记录冻结使用时的资产标题。Canvas 内容 origin 冻结标题，并保留只读 `asset_id` 用于识别同一资产。
因此后续重命名、编辑或删除资产都不会改写既有内容，也不能从来源名称跳回资产。

旧版本化目录在 server 启动时执行一次性升级：先生成时间戳完整备份，再保留每个资产的最新内容、恢复
归档资产并把旧作业/画布引用转成标题快照。新运行时只读取单内容 schema，永不读取迁移备份。

该决定取代 ADR-0010 中“Studio/Canvas 传递总是复制为目标项目独立版本”的部分；Canvas Project 包与
WebDAV 的不可变同步快照设计继续有效。

## 2026-10-25 修订：参考资产节点去重

用户选择保留只读资产 ID。转入后的 Content Version 仍由画布独立拥有；资产改名、换图或删除均不更新既有画布内容。Agent 的 `add_asset_node` 按当前节点内容版本的 `origin.asset_id` 去重，命中时复用该节点与冻结版本，并将同批后续连线中的请求节点 ID 改为真实 ID。旧标题快照没有资产 ID，不根据标题或摘要猜测归属。

这取代「Canvas origin 只保留标题」的限制，不引入回写、自动同步或可点击的资产关联。项目包保留这份只读出处。
