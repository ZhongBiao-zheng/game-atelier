# Triage Labels

| Canonical role | Local status | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待确认范围与价值 |
| `needs-info` | `needs-info` | 等待补充必要信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整,可直接实施 |
| `ready-for-human` | `ready-for-human` | 需要人工完成或判断 |
| `wontfix` | `wontfix` | 明确不实施 |

本地任务的 `Status:` 使用右列字符串。除非本文件被主动修改,Skill 不创建新的同义状态。
