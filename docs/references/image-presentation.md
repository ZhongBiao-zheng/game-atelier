# 工坊产物如何呈现给画师

当前工坊 Skill 的媒体入口是受限 MCP，文件仍在原项目目录。
与 [MCP 工作流](workshop-mcp-workflow.md) 一起使用，不从任意文件路径读取图片。

## 生成状态与预览分开判断

先以 `workshop_get_generation` 返回的**本次 request ID** 状态和实际产物确认生成是否完成。
然后以返回的媒体 ID 调 `workshop_read_media`。不要根据文件名、修改时间、旧版或“latest”
猜本次输出，不从预览是否显示来推断生成成功与否。

图片作为 MCP ImageContent 返回，客户端可展示，模型支持图片输入时可用于视觉检查。
模型或客户端不支持图片预览就明示限制，引导用户在已鉴权的 Atelier 当前对象查看；
不能谎称已看图，也不要因为客户端没显示就重新生成付费图片。

## 尺寸与播放

- MCP 图片是有界预览，不是完整原图；实际 width / height 来自返回的媒体元数据。
- 高清检查、下载、版本比较与手工定稿在 Atelier 原角色 / UI 页面中完成。
- 视频与音频工具目前只返回登记元数据，不返回完整视频 / 音频内容。
  用户在企划页面播放；Agent 不能据元数据声称看过全部镜头或听过声音。

## 安全边界

不提供 token、绝对敏感路径或未经鉴权的 /api/raw 链接。MCP 不注册虚假的资源 URI。
本机 Web 的媒体 API 另有会话、目标与登记素材校验，不能用 job_id 冒充身份鉴权。
不要为展示媒体去读取 data root、拼临时 URL、改文件权限、关闭鉴权或做 base64 文件兜底。
在宿主能直接展示工具图片时优先展示工具结果，不把图片编码再复制到文本。

收尾报告真实状态、目标与版本 / 媒体标识；无法内联显示时说明“请在 Atelier 当前对象查看”。
