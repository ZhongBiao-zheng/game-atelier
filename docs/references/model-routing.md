# 出图模型选择与提示词写法

Character、Promo、Turnaround 共用本规则。先通过 `workshop_list_models` 读取当前目标
可用 alias / model / 能力，再按任务选择；不读取 Key 文件、不猜模型名或价格。
用户点名优先，不可用时解释并请用户选择替代，不能偷偷换供应商。

## 按任务选择

| 任务 | 原工作流偏好（仅在实际可用时） |
| --- | --- |
| 常规立绘 / KV / 三视图 | GPT Image 系列 |
| 局部画风 / 质感 / 瑕疵调整 | Nano Banana 系列 |
| 用户已指定模型 / 厂商 | 以用户选择为准 |

偏好不是可用性保证；以工具返回的模型 ID、尺寸、参考数量、质量档能力为准。
有多个可用项时沿用本轮已经明确的选择；仍有费用或行为差异且无法确定时问用户。
没有可用模型就指向 Atelier 供应商设置，不给 Agent 供应商 Key。
模型与费用状态展示在待批准请求中；缺失价格不能写成零。
最终通过 `workshop_prepare_generation` 准备请求，人工批准在本机页面完成。

## 按模型族调整表达

GPT Image 通常用自然语言讲清主体 → 动作 / 姿态 → 风格 → 镜头 → 必要视觉锚，
明确指令优先，不堆形容词和长排除段。

Nano Banana 的局部质感编辑可把改点拆成具体短句，例如“减少过度锐化、统一笔触方向、
收紧暗部细节”。每点对应真实问题，不为了细致反复重述身份，不加入没有要求的变化。

参考图编辑的三个意图要区分：
A 编辑当前图：带当前登记图、只写差异；
B 整张重画：明确哪些锚仍保留；
C 参考构图大改：分别说明身份锚与构图来源，不能把场景图中的人复制成主角。
所有实际参考通过有序 media_ids 提交，来源与用途写进 Prompt。
