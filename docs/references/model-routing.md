# 出图模型选择 + 按模型族写提示词

三个出图 Skill（character / promo / turnaround）共用本规则。目标：不再只读「默认 Key 的第一个模型」，而是**按任务挑模型**，并**按所选模型族调整提示词写法**。

## 一、选模型（按任务，从 available_keys 里挑）

turn-start 返回 `available_keys[].models[{name,id}]`，这是可选池。按任务定目标族：

| 任务 | 首选模型族 | 命中 id 的关键字 |
|---|---|---|
| **常规出图**（绝大多数立绘 / KV / 三视图，**默认**） | GPT Image 2 | id 含 `gpt-image` |
| **画风 / 质感 / 细节调整**（换风格、改质感、修瑕疵、降破碎感等） | nano-banana | id 含 `nano-banana` 或 `nano_banana` |
| 用户点名某模型 / 厂商 | 照用户 | — |

挑选步骤：

1. 判断任务类型 → 目标族。
2. 在 `available_keys` 里找 `id` 命中目标族的 model，记下它的 `alias` + `id`。
3. 出图：`submit --kind <kind> --alias <alias> --model <model-id> --prompt-file ...`。
4. **找不到目标族** → 回退 `preferred_alias` 的默认模型，并一句话说明（如「未配置 nano-banana，改用默认 gpt-image」）。
5. `preferred_alias` 为 null 且无任何可用 Key → 停下，告知缺 Key。
6. 选定的模型会出现在**出图确认卡**上，画师过目即确认——**不必为「选哪个模型」单独发问**，除非任务类型本身模糊才确认。判据：**改动是否只是对已出图做局部质感 / 风格 / 瑕疵调整**——是（≈三模式 A）走 nano-banana；首次出图、整张重画（B）或带参考图大幅重写（C）走 gpt-image。

> 永远不在终端 / 文档 / log 里显示 access_key / secret_key。用户点名 alias/provider 时切换并更新 spec.md 记录的模型。

## 二、按模型族写提示词

提示词写法**随所选模型族变**，不是一套通吃。

### GPT Image 2（默认）—— 当「实习生」用

- GPT 对提示词要求不高、自己会补全合理细节。**把它当一个聪明实习生：讲清「做什么」即可。**
- 写法：自然语言成句，交代主体 → 动作/姿态 → 风格档 → 镜头 → 关键视觉锚点。明确指令优先。
- **不**堆形容词、**不**写长排除段、**不**用词海凑数。明确 > 啰嗦。

### nano-banana —— SD 词组式，越细越好

- 把想要的效果**拆到最小单位、逐条写成词组**，类似早期 Stable Diffusion 提示词。每个效果单独一条，不合并成模糊长句。
- 示例（改图 / 质感调整）：
  ```
  减少画面破碎感，降低裂纹数量，减少过度锐化效果，柔化高光过曝，统一笔触方向，收紧暗部细节
  ```
- 相当于把目标图「用最小单位描述」铺开：每一个要增强 / 削弱的点都点名。改图时尤其如此——逐项写清增强什么、削弱什么。

## 三、与「修改已出图三模式」的关系

风格 / 质感调整通常走 A 模式（编辑当前图，带参考图）。此时模型选 nano-banana、提示词用上面的 SD 词组式逐条写改动点，效果最佳。
