# 游戏美术 Prompt 系统规范

所有角色出图 prompt 的共享底层。立绘 / 美宣 / 三视图继承本规范,各自附加专项控制(见末节路由)。

---

## 一、视觉锚点

写 prompt 前先从 `spec.md` 提取锚点字段。**锚点一经确立,未经画师授权不得修改或"优化重写"——改了配色就是另一张概念图,不是变体。**

| 锚点字段 | 冻结级别 | 说明 |
|---|---|---|
| 发色 / 发型轮廓 | 🔴 硬锁定 | 立绘首张确立后不得变 |
| 瞳色 | 🔴 硬锁定 | 同上 |
| 服装主色调 + 整体轮廓 | 🔴 硬锁定 | 颜色和剪影不动 |
| 风格档(写实 / 半写实 / 卡通) | 🔴 硬锁定 | 整个角色生命周期内不变 |
| 武器 / 标志性道具形态 | 🟡 强参考 | 形状保留,局部细节可演绎 |
| 头身比 | 🟡 强参考 | 三视图中升为硬锁定 |

初稿与锚点不符时停下,问画师"这次要重定义视觉吗",不默改、不假设"微调可以"。

---

## 二、约束强度

两个正交维度共同决定本轮改动锚点的自由度:`generation_mode`(本轮是什么动作)× `consistency_level`(图类的固定档位)。

**generation_mode**

| 模式 | 触发条件 | 约束强度 |
|---|---|---|
| `first_gen` | 该角色该图类从未出过图 | 中。spec 不完整时可合理推断,但须把推断告知画师。 |
| `variation` | 画师说"再来几张" / "换个角度" / "换个情绪" | 中。视角 / 姿势 / 场景可变,锚点严格不变。 |
| `refinement` | 画师给出具体改点("背景改黄昏" / "发色再深一点") | 高。只改指定内容,其余锚点原文保留,不顺手优化。 |

`refinement` 硬规则:未被本轮改点涉及的锚点,逐字继承上一轮 prompt 原文,不允许"改完整体润色一遍"。

**consistency_level**(图类固定,不因画师要求降低)

| 级别 | 适用图类 | 含义 |
|---|---|---|
| `strict` | 三视图 | 所有锚点冻结,不允许任何创意延伸 |
| `standard` | 立绘 | 锚点冻结,姿势 / 视角 / 道具演绎适度开放 |
| `loose` | 美宣 | 锚点冻结,场景 / 光线 / 情绪大幅自由 |

## 三、参考图协议

写 prompt 前先确认本次参考图配置。参考图需要语义化区分,不是"塞进去就好"。

**两种角色**

| 角色 | 作用 | 画面地位 |
|---|---|---|
| `subject_image` | 主体保留图——提供核心主体的外观、结构、颜色、材质、关键识别特征 | 最终画面的"谁" |
| `reference_image` | 视觉参考图——提供风格、构图、色彩、光影、版式、氛围 | 最终画面"长什么样" |

关键规则:`subject_image` 存在时,`reference_image` 里的人物 / 主体不得替换核心主体——它只贡献视觉语言,不贡献身份。

**基础设施约束**

jobs schema 当前只有单 `source_image` 字段(`--source-image <绝对路径>`),不原生区分 subject / reference。区分在 prompt 文本层做,让模型读懂上传图的角色:

- 作 `subject_image`:写"以上传图主体为画面核心,保留外观 / 服装 / 比例 / 关键识别特征"。
- 作 `reference_image`:写"上传图仅供风格 / 构图 / 氛围参考,不复制其中主体身份"。
- 双图字段未来升级后,本协议不变。

**reference_mode(参考范围)**

用 `reference_image` 必须显式声明 mode 并在 prompt 中体现:

| mode | 含义 | 典型场景 |
|---|---|---|
| `full_reference` | 风格 + 构图 + 色彩 + 光影 + 版式 + 氛围 | 美宣承接画师"我想要这种感觉的图" |
| `style_only` | 风格、视觉气质、材质感、笔触 | 画师贴一张画派截图("Loish 风格") |
| `composition_only` | 构图、主体位置、画面重心、视角、留白 | 三视图参考 ArtStation 设定集布局 |
| `color_lighting_only` | 色彩系统、冷暖关系、光影氛围 | 美宣"我想要这张图的色调" |
| `pose_only` | 姿势、动作、肢体关系 | 立绘"按这个姿势画我的角色" |

**文本怎么表达参考关系**

单图(仅 `reference_image`):prompt 第 1 段末句写"参考上传图的 [对应 mode 内容],不复制其中主体身份"。例:`...以此外观作为角色视觉基准。参考上传图的整体风格、笔触和色调,不复制其中的人物身份。`

双图(`subject_image` + `reference_image`):第 1 段写 subject 决定核心主体("以上传主体图角色为画面核心,保留外观、服装、关键识别特征");另起一句写 reference 的参考范围("参考风格图的 [对应 mode 内容],不复制其中主体")。涉及参考图人物时写"重新生成符合主体的人物,保留参考图中人物参与展示的画面关系",不写"不要使用参考图人物" / "删除人物"。

人物保留规则(双图 `full_reference` 专属):`reference_image` 含人物且 mode = `full_reference` 时,保留参考图人物的基础属性(性别、大致年龄段、人数、气质、广告展示角色),但不复制其身份、面部、原始姿势或服装。

**各图类默认行为**

| 图类 | 默认 `subject_image`(skill 显式传 `--source-image`) | 画师上传图默认 mode |
|---|---|---|
| 立绘 first_gen | 无 | `reference_image`, `style_only` |
| 立绘 variation / refinement | `characters/<id>/portrait/v<n-1>.png` | `reference_image`, `full_reference` |
| 美宣 | `characters/<id>/portrait/v_latest.png`(必须,锚定角色) | `reference_image`, `full_reference` |
| 三视图 | `characters/<id>/portrait/v_latest.png`(强制,主体不变) | `reference_image`, `composition_only` |

`subject_image` 不是"隐式自动注入":runner 只把 skill 显式传入的 `source_image` / `reference_images` 转发给 provider,**不会自动去补任何图**。所以美宣 / 三视图要锚定角色,skill 必须主动把最新立绘 `portrait/v_latest.png` 作为 `--source-image` 传入(画师没另传 subject 时也是)。美宣第 1 段明确继承主体身份;三视图走参考图简化模式,不展开 spec 全量锚点,只补视图组合、姿势、基线和逐面结构信息。

## 四、输出格式

prompt 以**自然段式中文**输出,3～4 段,每段 1～3 句。锚点融入句子,不单独枚举。

**例外:参考图编辑 / refinement**

基于现有图做编辑(皮肤、换色、局部服装)时不套完整立绘模板——参考图已承载角色身份、比例、表情、姿态、画风,文本只提供差异指令。输出 1～3 段、约 120～260 字:

- **锁基线**:开头写"保持当前整体画风不变",给模型继承而非重画的起点。
- **点题**:第 1 句说明参考图与目标主题。
- **收敛改点**:只写本轮要改的颜色 / 服装局部 / 背景,2～4 个,每个是可执行画面指令("袖口改成深褐色")而非抽象诉求("更高级一点")。
- **正向表述**:改点写成目标状态,不用否定词("不要红色" / "去掉帽子")——否定句易触发重画或画风漂移。
- **收边界**:末句圈定不动项,如"不改武器、不加特效、不改动作"。

此模式不重述完整 spec 锚点(会被当成 first_gen 重画),不套 first_gen 的身份 / 服装 / 姿势 / 风格四段模板。

## 五、措辞红线

prompt 文本层的全局禁忌,所有图类、所有模式通用:

- **空洞质量词**:`masterpiece` `best quality` `8k` `高质量` `影视级` 不写。
- **网文滥词**:`凄美绝色` `倾国倾城` `绝世容颜` 不写。
- **自相矛盾**:同一 prompt 不并存冲突描述(如"浅色背景" + "深夜氛围")。
- **默认排除段**:不预设 negative prompt,优先正向描述约束画面;确需排除上版问题时,由专项规则或画师需求显式触发,且只写具体问题。
- **模块标题**:不用【主体】【光线】【风格】这类【】分段。
- **清单结构**:不用逐项列表、分号罗列。
- **篇幅**:正文不超过 4 段。
