# 美宣 Prompt 系统

继承 `art-prompt-system.md` 所有规则。

**美宣的核心任务**：用一张图讲一个关于这个角色的故事，让玩家看一眼就记住她。构图/光线/场景的决策优先级**高于**服装细节。

consistency_level: `loose`

---

## 零、写作哲学（高优先级，每次写 prompt 前回看）

> 重质量不重数量。能用几句话说清楚就不要啰嗦。要引导不要限制。通过结构引导方向，不强行规定每个细节。减少矛盾干扰，前后不矛盾，不堆砌辞藻。

具体落地规则：

1. **零外观罗列**：当 source_image 是立绘时，**情节段**（第2段）**禁止**写发色 / 瞳色 / 皮毛色 / 服装色 / 装备颜色 / 头饰名称。立绘已锚定外观，prompt 再写一遍只会和图打架。参考图协议句（"以上传图中的角色为画面核心，保留其外观与识别特征"）由前置的**主题段**（第1段）承担。
2. **每段 1-3 句**：5 段总长控制在 230-320 字。多于 320 字一定有冗余，去掉。参考火栗狐 promo v2（新 5 段框架）/ 幼皇猴 promo v1（旧 4 段框架，280 字）/ 烈拳猴 promo v1（旧 4 段框架，230 字）。
3. **正面陈述优先**：不要写"不参考其 A / B / C / D"长串否定 — 长串否定会反向激活模型。改写成正面"参考其 X"就够；要去掉的内容用画面正面描述自然挤掉。
4. **不写排除段**：美宣 prompt 默认只写正向画面描述。需要避免的方向用正面描述自然挤掉，不在 prompt 末尾追加"排除："段。
5. **不要精确坐标**：写"角色顶天立地占据画面右侧"比"角色位于画面 60-75% x 0-100% y 区间"好。引导方向不规定坐标，模型有发挥空间也不会跑偏。
6. **不堆砌辞藻**：禁用"高质量 / 精细 / 影视级 / 8k / 大师级"；改为具体描述（哪部分高细节、哪部分柔焦留白）。
7. **默认出无字底图**：标题 / 标语 / logo / 角色名 / 任何成段文案**不写进 prompt**——AI 渲染中文极易糊字 / 乱码，文字一律交本地排版层。`text_zone = 是` 时只在画面**留出**文案空白区（构图层面），prompt 里不写实际文字。例外仅两种：① 画师显式要求、且只是极短英文 / 数字（如 "VOL.1" "S2"）；② 画师明确说"文字也画进图"并在出图确认卡上过目认可。两种例外都要在 spec.md 美宣记录标注。

## 一、写 prompt 前的输入核查

| 输入项 | 来源 | 缺失时 |
|---|---|---|
| spec.md 视觉锚点（全部） | spec.md | 必须先有角色 spec，否则退回 `/game-atelier:character` |
| 每个出镜角色的身份锚 | 定稿/最新 portrait、定稿/最新 turnaround、用户上传图任选其一 | 缺失的角色先请用户上传参考图或补角色资产 |
| `narrative_beat` | 画师要求 | **必填，不允许为空**。"凄美"不是 narrative_beat，"闭眼跪地准备最后一次唤神"才是 |
| `target_aspect_ratio` | 画师要求 | 必填。见画幅映射表 |
| `text_zone` | 画师要求 | 默认 `否`。是否预留文案留白区 |

**narrative_beat 不能为空的原因**：没有情节锚点，模型会退化成把所有细节堆在一起，输出"华丽但无情绪"的立绘变体，而不是能讲故事的美宣。

## 二、画幅 → 构图映射

拿到 `target_aspect_ratio` 后，按以下映射确定构图策略。这一步在写 prompt 前完成，不在写的过程中摸索。

| 画幅 | 构图策略 | 典型用途 |
|---|---|---|
| `16:9` 横版 | 角色占左侧或右侧 2/3，另侧留场景/文案空间；或角色居中 + 全景场景铺满 | 官网 KV、横幅广告 |
| `4:5` 竖版 | 角色占 3/4 画幅，场景紧凑收拢，视觉张力集中 | 社媒竖版卡、手机壁纸 |
| `1:1` 方图 | 角色半身特写 + 氛围背景，快速传递情绪 | 头像卡、商品方图 |
| `9:16` 全竖 | 角色全身 + 场景纵深，视角感强 | 手机闪屏、Story 广告 |

## 三、决策顺序：先光线，后服装

**这是美宣与立绘最本质的区别。**

光线决定情绪基调 → 情绪基调决定场景温度 → 场景温度决定服装细节该强调什么。

把光线留到最后写等于把情绪交给模型猜。写之前先在脑子里回答这一句话："这张图的光从哪里来，打在什么上面，产生什么情绪？"

## 四、段落结构与每段规则

> **结构演进**：2026-05-22 起从 4 段升级为 5 段，前置一段"主题声明 + 参考图协议"。
> 旧 4 段范例（young-emperor-monkey / blazefist-monkey）仍保留在第八节供对照。

### 第1段：主题声明 + 参考图协议（前置锚定段）

**写什么**：单句声明图像类型与画幅 + 按上传顺序逐张说明参考图的简短可见特征与用途。

**模板**：
```
游戏美术宣传海报 · <角色名/角色组合> KV · <画幅> 横版/竖版构图。第一张参考图对应<角色A>：<1～3个可见特征>，作为角色身份锚；第二张参考图对应<角色B>：<1～3个可见特征>，作为角色身份锚；第三张参考图是<场景简述>，仅参考<场景/构图/光线/色彩>。
```

**规则**：
- 必须位于整个 prompt 最前面，不允许被情节描述穿插或挤后
- 图像类型词（"游戏美术宣传海报"/"角色 KV"）锁定 AI 的创作 mode，避免模型把美宣画成杂志插图、概念草稿或剧情漫画
- 参考图协议提前，让 AI 在读情节描述前就完成角色身份锚定，再去消化动作/光线/构图
- **可见特征明确**：不能只写“第一张是阿豆”。至少补颜色、材质、轮廓或标志物中的 1～3 项，让模型能把文字与对应图片绑定；场景图同样给简述。

### 第2段：情节锚点

**写什么**：角色在做什么（具体动作 + 情绪状态）+ 场景时空（地点 + 时辰/天气）。

**规则**：
- `narrative_beat` 必须转化为具体动作描述。"孤独"不行，"独站高塔边缘，风将发丝从耳后带走，不回头"才行
- 场景时空必须给具体值。"夜晚"太虚，给"子夜，月被云蚀只剩一弧白光"
- 这段是全 prompt 的叙事锚，决定后续所有段落的情绪方向
- **强禁止外观罗列**：当 source_image 是立绘时，本段不允许出现发色/瞳色/皮毛色/服装色/装备名称及颜色 — 立绘已锚定，写一遍只会和图打架（参见零节规则 1）。参考图协议已由第1段承担，本段**不再写**"以上传图中..."的指向句

### 第3段：光线 + 色彩基调

**写什么**：光源方向 + 光源性质（硬光/柔光/体积光）+ 主色调 + 辅色调 + 明暗对比关系 + 是否逆光/剪影。

**规则**：
- 这段每个值必须具体，不允许模糊。"暖光"不够，给"黄昏低角度侧逆光，主色暖金，阴影面冷蓝灰，高对比"
- 若有第二光源（法杖/武器/道具发光）必须单独说明，给色温和亮度关系
- 先定光的方向（叙事情绪），再决定辅色（视觉平衡），而不是反过来
- 剪影处理是情绪放大器，但会损失服装细节 —— 使用前问画师是否接受

### 第4段：构图 + 镜头

**写什么**：视角选择 + 焦点物体 + 画幅比例 + 留白策略 + 文案预留区位置（若 text_zone = 是）。

**视角决策规则**：

| narrative_beat 情绪类型 | 推荐视角 |
|---|---|
| 史诗/战前/仪式/降临 | 低视角仰拍，角色有压迫感 |
| 内心独白/决意/静默 | 平视，镜头感克制 |
| 凝视/审视/俯瞰全局 | 略俯视，角色有掌控感 |
| 颓然/失落/虚弱 | 略俯视或平视，不做仰拍 |

**焦点规则**：焦点必须是"决定这张图情绪的那个元素"—— 可以是脸、手、武器、特定道具、甚至一块空白。说清楚，不要让模型猜。

### 第5段：风格与质感

**写什么**：风格档（继承 spec，写 spec 里的原话）+ 参考画派 + 细节密度 + 是否有特殊处理（留白/印象式笔触）。

**规则**：
- loose 模式允许强化光影风格（比 spec 更戏剧化的光影处理），但基础风格类型不变（半写实不变卡通）
- 细节密度：注意力越集中的区域细节越高，其他区域可适当简化（裙摆/背景做留白处理）
- 禁止写 `细节丰富` `精细刻画` 等无意义词，改为具体说哪里高细节

## 五、多参考图处理（重要：实际行为）

### 5.1 选图

`workshop_prepare_generation` 接收当前目标已登记的有序 `media_ids`，经本机人工批准后由 runner 传给 provider。美宣按以下顺序组织：

1. 先放角色身份锚。每个出镜角色至少一张，优先定稿 portrait，其次最新 portrait、定稿/最新 turnaround、用户上传参考图。
2. 同一角色若一张图看不清背面、比例或材质，可追加互补视角；不为了凑数重复上传近似图。
3. 再放场景、构图、风格、光线或姿势参考图，逐张指定 `reference_mode`。
4. 每张原图分别上传，不预先拼成联系表；如果所选模型的参考图上限不足，先和画师一起删减低优先级图。

### 5.2 参考图清单与 prompt 绑定

Prompt 第一段必须覆盖**每张参考图**，顺序与 media_ids 完全一致。每项只需一句简单描述：

```text
游戏美术宣传海报 · 阿豆与青团丁初遇双角色 KV · 16:9 横版构图。
第一张参考图对应阿豆：黄色调、熊耳帽的毛绒 PVC 玩偶；第二张参考图对应青团丁：淡黄绿色圆团毛绒生物、头顶单片叶子；两位角色均保留各自外观、材质、比例与关键识别特征。
第三张参考图是月夜木桥：湿木板、冷蓝月光和萤火，仅参考场景与光线。
```

- 角色描述写颜色 / 材质 / 轮廓 / 标志物中的 1～3 项，不重述整份 spec。
- 场景描述写地点 / 主体物 / 光线 / 色调中的 1～3 项，不只写“参考第三张氛围”。
- 视觉参考含其他人物时，明确它只贡献指定视觉语言；角色身份始终由身份锚决定。
- 提交后核对确认卡的参考图数量、顺序与 prompt 清单一一对应。

### 5.3 记录来源

在 spec.md 美宣记录里写完整 media ID 与名称列表及每张用途，不只记录第一张 `source_image`，方便未来回查和迭代。

## 六、质量门控

| 检查项 | 不通过时 |
|---|---|
| 第1段先写主题声明，再完整写参考图协议？ | 补前置段，把参考图协议从情节段挪上来 |
| 每张参考图都有按顺序的简短可见描述与用途？ | 补齐参考图清单，再核对 media_ids 顺序 |
| narrative_beat 已转化为具体动作？ | 退回，继续问画师"她在做什么动作" |
| 光线已确定方向和色温？ | 返回第3段补完 |
| 构图策略与画幅匹配？ | 按画幅映射表核对 |
| prompt 中所有 spec 锚点（发/瞳/服装）均正确继承？ | 退回修正 |

## 七、排除段

**不写**。美宣 prompt 只保留主题、情节、光线、构图、风格五段正向描述；不要在正文之后追加 `排除：` / negative prompt。

如果上一版出现明确反向问题，把修正转成正向画面约束写回对应段落。例如不要写"排除真人写实"，改写为"保持卡通三国武将插画，粗轮廓线与清晰色块"。

## 八、示例

### 3:2 横版 KV · narrative_beat = 雪松林斜坡纵跃下冲的爆发瞬间 · 立绘作 source · 无排除段 ⭐ 新 5 段框架

(实战示例：char-1779358169/promo/v2.png · 310 字 · 火栗狐冬季 KV)

```
游戏美术宣传海报 · 火栗狐角色 KV · 3:2 横版构图。以上传图中的狐狸角色为画面核心，保留其外观与识别特征。

情节：火栗狐从雪松林斜坡纵跃下冲的爆发瞬间——3/4 侧向腾空，后蹄刚蹬开一团雪粉，尾巴向后拉成弧线，身后一道蜿蜒滑痕没入松林。时间是隆冬清晨刚日出。

光线：清晨低角金色阳光从画面深处穿过雪松针逆射而来，将炸起的雪粉雾化成金白色体积光圈，角色背部与尾巴边缘形成锐利金边光。主色调冷蓝雪与暖金逆光并置，阴影面冷靛蓝，高对比。

构图：超低仰角贴雪面广角拍摄，角色顶天立地占据画面中央偏右腾空位置，雪坡由右下向左上铺向松林深处。后蹄踢开的金色雪粉团与尾巴弧线落在视觉焦点；左上松林开口透下金光放射，远景柔焦留白。

风格：清晰黑色轮廓线，平涂上色，柔和边缘阴影，卡通插画风格。脸部、后蹄雪粉、金边光与尾巴弧线为高细节区，远景松林与雪坡阴影做柔焦留白。
```

**为什么前置主题段有效**：第一句"游戏美术宣传海报 · 角色 KV"让 AI 在读后续描述前进入"海报"创作 mode，避免被情节描述当成"4 段插图分镜"或"绘本场景"处理；第二句参考图协议提前完成角色身份锚定，AI 不需要在第3段后才想起来"这是哪个角色"。

**示例共性**（每次写 prompt 自检）：
- **新 5 段框架**：主题声明 + 参考图协议 → 情节 → 光线 → 构图 → 风格，总长 230-320 字
- **旧 4 段框架**（保留对照）：情节 + 参考图协议合并 → 光线 → 构图 → 风格，总长 230-280 字
- 零外观罗列（皮毛色/王冠/拳套配色等全部交给立绘）
- 第1段一定包含"游戏美术宣传海报 · 角色 KV · 画幅" + "以上传图中的[生物]角色为画面核心"
- 无排除段
- 不写精确坐标，用"左下三分之一 / 顶天立地占据右侧"这种引导式
- 每段一句"高/中/低细节区"分配（最后一段）
