# 立绘 Prompt 系统

继承 `art-prompt-system.md` 所有规则。

**立绘的核心任务**：确立该角色的视觉身份标准图。第一张立绘的锚点决定所有后续图（美宣/三视图）的参照基准。

consistency_level: `standard`

---

## 一、写 prompt 前的输入核查

在起笔前，必须收集以下信息。缺项说明如何处理。

| 输入项 | 来源 | 缺失时 |
|---|---|---|
| spec.md 视觉锚点（全部） | spec.md | first_gen 时可推断，但必须告知画师推断内容 |
| `generation_mode` | 画师信号 | 默认 `first_gen` |
| `pose_type` | 画师要求 | 默认 `全身正面直立` |
| `background_type` | 画师要求 | 默认 `纯色浅背景`（见背景规则） |
| `target_aspect_ratio` | 画师要求 | 默认 `2:3` |

---

## 二、段落结构与每段规则

### 第1段：角色规格（identity）

**写什么**：角色主体身份 + 职业/气质 + spec 中最核心的三个视觉锚点（发色/瞳色/服装主色）。

**规则**：
- 只写"让人一眼认出是这个角色"的信息，不堆砌装饰细节
- 必须从 spec 直接继承发色、瞳色、服装主色，不改词、不扩写
- first_gen 且 spec 里头身比缺失 → **停下**，问画师："七头身还是八头身？" 头身比决定后续所有比例

### 第2段：服装与道具

**写什么**：服装主结构 + 关键材质质感 + 手持/佩戴道具。

**规则**：
- 颜色必须给具体值。"暗金刺绣领口" 而非 "金色装饰"；"霜白缎面" 而非 "白色"
- 道具必须说明持握方式和大致位置（"右手轻握于身侧"不是"手持法杖"）
- refinement 模式：本段只改画师指定内容，其余原文保留

### 第3段：姿势、构图、背景

**写什么**：站姿/动作描述 + 视角 + 背景处理 + 画幅比例。

**背景规则（重要）**：
- **first_gen 首张必须纯色或极浅渐变背景**。复杂场景背景会干扰角色识别度，场景留给美宣做
- background_type = `场景` 时 → 提醒画师此选择会降低角色用于后续生产时的可用性

**姿势规则**：
- first_gen 默认正面直立全身，作为身材比例基准图
- variation 模式才开放动态姿势（动作幅度应在"识别度不受影响"范围内）

### 第4段：风格与质感

**写什么**：风格档（继承 spec）+ 参考画派 + 细节密度 + 光线方向。

**光线规则**：
- 立绘默认"正面柔光"，不做戏剧化侧光/逆光/强阴影
- 戏剧化光影会掩盖角色结构 → 留给美宣

## 三、参考图处理（继承 art-prompt-system 第三节）

立绘的参考图配置因 generation_mode 而异：

| generation_mode | subject_image | reference_image 默认 mode |
|---|---|---|
| `first_gen` | 无 | `style_only`（画师上传的参考画派/IP 截图） |
| `variation` | 当前角色明确选定的已登记立绘（以 media ID 传入，身份锚与 spec 一致） | `style_only` 或 `pose_only` |
| `refinement` | 本次选定的上一版立绘 media ID | `full_reference`（如果有改风格意图） |

**写 prompt 时的参考图表达**：
- 先按 media_ids 顺序建立参考图清单；每张都写序号、1～3 个可见特征和用途。角色图、风格图、姿势图一视同仁，不能只写“图一 / 图二”。
- first_gen 且画师有上传参考画派截图 → 在第4段（风格）补一句："参考上传图的整体笔触、材质感和影调（style_only），不复制其中的人物身份与服装。"
- refinement 模式 → 在第1段后补一句："以上一张实际选定的参考立绘作为主体保留图，外观、服装、配色、比例严格继承。"
- 立绘禁止 `composition_only` 单独使用（立绘构图是标准正面直立，没必要参考别人）

### 3.1 皮肤 / 换色编辑短模板

当已有默认立绘，画师要做品质皮肤、换色、换装、局部服装样式调整时，generation_mode = `refinement`，参考图作为 `subject_image`。这不是首张立绘生成，不套用四段完整身份模板。

**写法目标**：参考图负责"这个角色是谁"，prompt 只负责"这次改什么"。

推荐模板：

```text
根据参考图中的角色立绘为参考，生成这个角色的"<皮肤名>"主题角色立绘皮肤。
将<默认服装/颜色>改为<目标服装/颜色>；<局部服装变化>；整体气质<目标气质>。
<新增局部记忆点>。简约白色背景。不改武器，不加特效，不改动作。
```

**质量门控**：
- 正文控制在 1-3 段，约 120-260 中文字
- 不重述脸型、瞳色、表情、道具等参考图已锁定的信息，除非本轮要改
- 绿色品质皮肤只写换色或局部服装变化；蓝色品质才写整体服装和饰品样式变化
- 不写长排除段；必要边界合并到最后一句

## 四、质量门控（stop-before 检查）

写完 prompt 初稿后，出图前做以下检查，任一不通过 → 停下解决再出：

| 检查项 | 不通过时 |
|---|---|
| prompt 中发色/瞳色/服装主色与 spec 一致？ | 退回修正，禁止带着偏差出图 |
| first_gen 且头身比未确认？ | 先问画师，缺省值不可靠 |
| 背景是否为 first_gen 推荐的纯色？ | 不是则提醒画师后果 |
| spec 风格档是否空白？ | first_gen 时必须先问画师要参考 IP 或参考图，不能盲出 |

---

## 五、排除段模板

> 门控：默认不写排除段（见三的「不写长排除段」）；仅当上版出现具体问题或画师显式要求时才用，能用正向描述约束画面的就不写否定句。

```
排除：现代感元素、卡通夸张脸、过曝白化高光、四肢比例变形、低质量线条、复杂杂乱背景细节
```

根据角色风格档调整：写实风补充 `手部骨骼扭曲`；卡通风补充 `写实皮肤质感`。

## 六、示例

### first_gen · 全身 · 2:3

```
圣灵祭祀，治愈系少女，七头身，金发束起留两缕碎发垂颊，琥珀色瞳。以此外观作为角色视觉基准。

白金圣袍长裙，正面胸口金线圣徽刺绣，袖口双层金丝镶边，右手轻持细长光辉法杖于身前，法杖顶端淡金晕光，左手自然垂落。

正面直立全身，略低视角增加气势，极浅暖灰纯色背景，2:3 竖版构图，重心略偏中，头顶留适当留白。

半写实精修，参考 Loish / Ross Tran 暖调厚涂，正面柔光均匀打亮，高细节但衣摆做简洁留白，线条清晰不模糊。

排除：现代感元素、卡通夸张脸、过曝白化、四肢比例变形、复杂背景细节、低质量线条
```
