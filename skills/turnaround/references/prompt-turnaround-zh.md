# 三视图 Prompt 系统

继承 `art-prompt-system.md` 所有规则。

**三视图的核心任务**：为下游建模师、动画师、卡牌画师提供可直接使用的技术参考图，而不是艺术欣赏图。一切决策服务于"让读图者能正确重建这个角色"。

consistency_level: `strict` — 所有锚点字段在三视图中**全部冻结**，不允许任何创意延伸。

---

## 一、写 prompt 前的输入核查

| 输入项 | 来源 | 缺失时 |
|---|---|---|
| spec.md **全部字段**（不只是锚点） | spec.md | **必须有完整 spec 才能做三视图**，否则退回 `/game-atelier:character` 补完 |
| `view_set` | 画师要求 | 默认 `正面/侧面/背面` 标准三联 |
| `coloring_style` | 画师要求 | 默认 `平涂`（见下游映射） |
| `downstream_use` | 画师要求 | 默认 `建模`（影响细节密度和线条风格） |

---

## 二、downstream_use → 风格映射

下游用途决定细节密度和着色要求，写 prompt 前先确认：

| downstream_use | 推荐 coloring_style | 细节密度 | 特殊要求 |
|---|---|---|---|
| `建模` | 平涂 / 线稿 + 平涂 | 中。结构清晰优先 | 比例尺辅助线必须有 |
| `动画绑骨` | 线稿 + 平涂 | 中。关节位置明确 | 手肘/膝盖/腰部接缝清晰 |
| `游戏卡牌` | 半厚涂 | 高。识别度和视觉冲击 | 可加 3/4 视角；表情包可选 |
| `服装设计` | 线稿 | 高。面料结构、接缝、分层 | 单独标注面料名称可选 |

---

## 三、严格禁止项（三视图专属）

以下内容**无论画师如何要求均不写入 prompt**，这是三视图的技术约束，不是风格选择：

- **禁止戏剧化光影**：逆光、侧光剪影、体积光、强暴闪 —— 会掩盖结构面
- **禁止特效装饰**：法术光效、散落花瓣、雨雪粒子、能量爆发
- **禁止动态夸张动作**：三视图必须中性站姿（T-pose 或自然 A-pose）—— 有动作参考图需求走独立出图单独处理
- **禁止复杂场景背景**：只允许纯色或浅色网格
- **禁止修改任何 spec 锚点**：包括"顺手把发型稍微调整一下" 这类微调
- **禁止三面比例不一致**：三面必须同一头顶线 + 同一脚底基线

若画师提出与以上禁止项冲突的要求，回应："三视图的技术约束不允许这样做，[解释原因]。如果你需要[画师想要的效果]，可以单独出一张[立绘/美宣/动作图]。"

## 四、参考图处理（继承 art-prompt-system 第五节）

三视图的参考图规则比立绘和美宣更严格，因为三视图是**主体保留极端值**的场景：人是谁绝对不能漂。

### 4.1 默认参考图配置

| 配置 | subject_image | reference_image |
|---|---|---|
| 默认 | `portrait/v_latest.png`（**强制**，不可选） | 无 |
| 画师上传布局参考图（ArtStation 三视图截图） | `portrait/v_latest.png`（强制） | 上传图，mode = `composition_only` |
| 画师上传服装结构参考图 | `portrait/v_latest.png`（强制） | 上传图，mode = `composition_only` 仅参考布局 |

### 4.2 禁用的 mode

三视图严禁以下 reference_mode：

- ❌ `full_reference` —— 会让 reference_image 中的人物身份污染主体
- ❌ `style_only` —— 三视图的风格已被 spec 风格档锁死，参考别人的风格 = 改 spec
- ❌ `color_lighting_only` —— 三视图无戏剧化光影，无色彩参考需求
- ❌ `pose_only` —— 三视图必须是中性 T-pose / A-pose，不接受姿势参考

唯一允许的 mode：**`composition_only`** —— 仅参考三联视图的布局方式（三面分布、辅助基线位置、表情包/道具特写的排列规律）。

### 4.3 写 prompt 时的参考图表达

- **无上传图（默认立绘 subject_image）**：走"参考图简化模式"。第1段只写"参考图中的[角色简述]，[风格]，生成这个角色的三视图展示画面"，再接视图组合、姿势、全身要求。禁止在第1段展开 spec 全量锚点；立绘已经承载外观，文字只补模型看不出来的工程结构。
- **有上传图，composition_only**：在第3段（画面规格）末尾补一句："参考上传图的三联视图布局方式和辅助基线安排（composition_only），不参考其角色身份、服装、色彩或风格。"
- **画师试图上传作风格参考时**：拒绝。回应："三视图的风格已由 spec 风格档锁定，参考别的风格等于改 spec。如果你想换风格，先回 /game-atelier:character 重新定 spec。"

### 4.4 spec 锚点 vs 参考图的优先级

冲突时永远以 spec 锚点为准。如果画师上传的参考图与 spec 不一致（如参考图角色是黑发，spec 是金发），按 spec 出图，不按上传图。这是三视图区别于其他图类的关键 —— **三视图不接受任何对 spec 的覆盖**。

## 五、段落结构与每段规则

### 第1段：角色规格 + 视图组合

**有参考图（subject_image）时**：大幅简化，采用曹操 v2 模板。直接写"参考图中的[角色简述]，[风格]，生成这个角色的三视图展示画面"，然后写视图组合、姿势、全身要求即可。禁止在第1段展开 spec 全量锚点——参考图已经承载了角色外观，文本只补充模型看不出来的结构要求。

**无参考图时**：spec 中**所有**锚点字段 + 头身比 + 本次视图组合逐项写出。写完后比对 spec，逐项核查是否遗漏。

**两种情况均须写明**：
- 视图组合（"正面/侧面/背面三视图横向排列"）
- 姿势优先用"双臂微微向下倾斜约 15 度的 T-pose（非水平 T-pose）"；异形/四足角色再改为适配物种的中性静态姿势
- 是否全身含脚底

**曹操 v2 经验**：
- 有 `source_image` 时，第1段短，越像"任务指令"越稳定；不要把 visual_dna / anchors 全量复述成外观清单。
- 姿势写成 15 度下倾 T-pose，比泛泛的"自然 A-pose"更容易让三面可读且不遮挡服装。
- 最后一段只写正向约束，不写 negative；三视图靠"平光、无方向性光影、浅灰网格、等高基线"收束画面。

### 第2段：多面可见信息

**写什么**：每个视图面各自"独家可见"的结构细节。

**规则**：
- **只写在该面上才能看到的信息**，已在其他面描述过的不重复
- 正面 → 侧面 → 背面，逐面列举专属细节
- 武器/道具在每个面的位置和角度都要说清（挂在身上的扣环位置、斜度）
- 道具特写单独算为附加视图，非默认

### 第3段：画面规格 + 技术要求

**写什么**：画幅（固定横版）+ 背景 + 辅助基线 + 三面分布比例。

**固定值**：
- 画幅：`1536×1024` 横幅，不接受其他比例
- 背景：浅灰 / 米白 / 浅蓝网格，选一种，不接受场景背景
- 辅助线：头顶线/腰线/脚底线三条基线，标配
- 三面分布：每面占画面宽度的 1/3

### 第4段：风格

**写什么**：风格档（继承 spec）+ 下游推荐的着色风格。

**规则**：
- 光线方向写"正面平光"或"柔光均匀打亮"—— 不能有方向性侧光
- 不写排除段（negative prompt）

## 六、示例

### 标准三视图 · 建模用 · 平涂

```
参考图中的狼形拟人武将形象，卡通三国武将风格，生成这个角色的三视图展示画面，视图组合：正面 / 侧面 / 背面三视图横向排列，三面严格等高基线对齐，双臂微微向下倾斜约 15 度的 T-pose（非水平 T-pose），全身完整显示，衣服盖过脚。

正面可见：胸前红金核心饰件完整图案，外袍正面开襟走向及金色边饰宽度，腰间系带正面结合方式，冠饰正面形态与中轴位置，右腰侧短剑刀鞘上缘露出轮廓。侧面可见：冠饰侧面高度及向后延伸长度，红色系带从脸侧绕至胸前的路径弧度，大黑毛领从颈部向肩部延展的厚度剖面，外袍侧面剪影和开叉起始高度，短剑从腰侧斜插的角度及刀柄朝向。背面可见：外袍背面开叉位置及衣摆分布，大黑毛领背部覆盖范围边界，红色系带在背面的走向，冠饰背面延伸结构。

1536×1024 横幅，浅灰底色配细线网格，头顶线 / 腰线 / 脚底线三条辅助基线，三联视图均匀分布，每面占画面宽度的 1/3。

卡通三国武将风格，粗轮廓线，色块清晰平涂上色，正面平光均匀打亮，无方向性光影，细节密度适合建模读图。
```

### 扩展三视图 + 表情包 · 卡牌用 · 半厚涂

```
圣灵祭祀，七头身，金发束起后发髻留两缕碎发垂颊，琥珀色瞳，白金圣袍长裙，正面胸口金线圣徽刺绣，袖口双层金丝镶边，右手持细长光辉法杖。视图组合：正面 / 3/4 侧面 / 背面三视图横向主体 + 右侧附表情包四格（标准表情：平静 / 微笑 / 惊讶 / 愤怒），三联主视图三面严格等高对齐。

正面可见：圣徽刺绣完整图案，袖口金线双层结构，法杖握持位置。3/4 侧面可见：右脸轮廓与发际线交界，法杖与身体角度关系，领口立领高度。背面可见：披风内衬纹样，腰带绑带，发尾金箍。表情包四格：每格 1/4 等宽，面部特写，统一白底，表情变化只改眉眼嘴，发型与领口不变。

1536×1024 横幅，浅蓝细网格背景，头顶线/脚底线基线，三联视图占左侧 3/4，表情包占右侧 1/4。

半写实半厚涂，线条清晰，局部高细节适合卡牌印刷，柔和正面平光。
```
