# 项目记忆 — 精灵收集游戏

## 世界观与设计语言

一款精灵收集 / 养成 / 战斗游戏，整体参考宝可梦式明亮图鉴风，精灵角色设计参考幻兽帕鲁与宝可梦的可爱高识别度路线。

- 角色轮廓：精灵设计优先清晰剪影、夸张但易读的属性标志
- 画风：卡通插画，清晰黑色轮廓线，水彩平涂或干净赛璐璐阴影，明亮饱和但不过曝
- 首轮示意：优先官方图鉴白底全身立绘，便于快速判断形态、属性与进化潜力
- 角色 id 命名：英文小写 + 连字符（`holy-spirit-priestess`）；显示名中文为主；出图序号 `v1.png / v2.png ...`

### Turnaround

- 2026-05-22 通用 · 侧视图（3/4 侧身）双臂一律下垂贴身体两侧，不用 T-pose 横展；避免近端胳膊/拳套挡住身体侧面轮廓，下游建模师才能读到侧面身形。prompt 片段：`侧视图：双臂自然下垂贴身体两侧，肩膀放松`
- 2026-05-22 通用 · A 模式（带参考图修改）prompt 只写「要变的」，不写「不变的」；参考图本身就是基线，「唯一需要修改」「其余沿用参考图」「XX 形态不变」全是废话噪音。极简到只剩改动指令一句话 + 画面规格。
